YOUR FIRST PROGRAM

Quick Start

What works in 0.2 →
  1. 01

    Get the compiler

    Build the compiler from source below. The 0.2 compiler is a development checkout; compiler installers are not published yet. The published 0.1V release contains the VS Code extension and setup instructions, with the compiler built separately. See the repository README for the available revision's setup.

    Source build: macOS ARM64 / Linux ARM64 or x86-64

    These steps target Apple Silicon Macs and Linux hosts on ARM64 or x86-64.

    Install Git, CMake 3.20+, a C compiler and a C++20 compiler. Native execution also needs Clang, a linker and the platform C runtime/SDK. This build uses AOT and does not require LLVM development libraries.

    git clone https://github.com/mirukuSora2026/Aevix-lang.git
cd Aevix-lang
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DAEVIX_ENABLE_JIT=OFF
cmake --build build --config Release --parallel 2

    These commands build the revision available in the repository. For the 0.2 features, use a checkout containing the 0.2 implementation described in the profile.

    The commands below use ./build/aevixc from the source build. With an installed compiler, use aevixc instead.

  2. 02

    Save hello.avx

    Create this file in the repository directory. No imports are needed for basic integer arithmetic.

    i32 square(i32 value) {
    return value * value;
}

i32 main() {
    return square(6) == 36 ? 0 : 1;
}
  3. 03

    Check and run

    ./build/aevixc --check hello.avx
./build/aevixc hello.avx
echo $?

    Expected exit status: 0. This example prints nothing. The first command checks types and ownership; the second compiles and runs the program, then removes its temporary executable.

    On Windows, a Visual Studio source build uses .\build\Release\aevixc.exe; PowerShell reports the exit status through $LASTEXITCODE. Native Windows execution of the 0.2 development artifacts remains unverified.
