YOUR FIRST PROGRAM

Quick Start

What works in 0.2 →
  1. 01

    Get the compiler

    Download the compiler installer for your platform from 0.2V preview and follow its installation guide. Packages include the Aevix runtime and register PATH. Install Clang and the platform linker/SDK separately for native compilation, then open a new terminal. The VS Code extension is a separate download on the same release page.

    Package filenames retain 0.2.0-dev. macOS packages require Apple Silicon and macOS 26.0+. Linux packages target Ubuntu 24.04/glibc 2.39; Windows x86-64 is experimental and AOT-only.

    Source build: macOS ARM64 / Linux ARM64 or x86-64

    These steps target Apple Silicon Macs and Linux hosts on ARM64 or x86-64.

    Install Git, CMake 3.20+, a C compiler and a C++20 compiler. Native execution also needs Clang, a linker and the platform C runtime/SDK. This build uses AOT and does not require LLVM development libraries.

    git clone https://github.com/mirukuSora2026/Aevix-lang.git
cd Aevix-lang
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DAEVIX_ENABLE_JIT=OFF
cmake --build build --config Release --parallel 2

    These commands build the current repository revision. See the 0.2 implementation profile for supported features and the README for JIT build options.

    The commands below use an installed aevixc on PATH. After a source build, use ./build/aevixc instead.

  2. 02

    Save hello.avx

    Create this file in your working directory. No imports are needed for basic integer arithmetic.

    i32 square(i32 value) {
    return value * value;
}

i32 main() {
    return square(6) == 36 ? 0 : 1;
}
  3. 03

    Check and run

    aevixc --check hello.avx
aevixc hello.avx
echo $?

    Expected exit status: 0. This example prints nothing. The first command checks types and ownership; the second compiles and runs the program, then removes its temporary executable.

    On Windows, PowerShell reports the exit status through $LASTEXITCODE. A Visual Studio source build uses .\build\Release\aevixc.exe. The Windows preview package is experimental.
