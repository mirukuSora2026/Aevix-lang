바인딩 구문변수 선언

타입 우선 선언, 불변 기본값, mut·rsn·const·persist, 대여한 지역 값.

함수 구문함수 선언

반환형 우선 구문, 값·참조 매개변수, 명시적 반환 경로, void·unit·never.

확정된 규칙

바인딩은 이름 앞에 타입을 적습니다. 기본적으로 불변이며 mut으로 변경을 허용합니다. rsn은 정적 타입 추론을 수행하고 const는 컴파일 타임 평가를 요구합니다. persist는 프로세스 수명의 저장소를 나타내며 다음 규칙을 따릅니다: 확정된 초기화·정상 종료 규칙.

T value는 값을 전달합니다. Copy 타입은 복사하고 소유한 non-Copy 값은 깊은 복사 없이 이동합니다. &T value는 공유 대여로 읽고 &mut T value는 독점 대여로 수정을 허용합니다. 호출에서는 x, &x, &mut x를 명시적으로 선택합니다. 이미 대여한 참조나 뷰 값은 그대로 전달합니다.

아래 바인딩과 함수 정의는 알맞은 상위 스코프에 놓이는 서로 독립된 예제입니다. 모듈 최상위 persist의 초기화는 다음을 따릅니다: 프로그램 시작 규칙.

i32 size = 128;
mut i32 count = 0;
rsn inferred = 128;
const i32 LIMIT = 100;
&i32 reference = &size;
i32 copied = *reference;

i32 identity(i32 value) {
    return value;
}

정상 종료하는 non-void 함수의 모든 경로는 값을 명시적으로 반환합니다. 반환 위치의 void는 본문 끝까지 진행하거나 값 없는 return을 허용합니다. unit 값 타입을 반환하는 함수는 unit 값도 명시적으로 반환해야 합니다. 끝나지 않는 경로에 불가능한 반환을 요구하지는 않습니다.

미정 사항은 미정으로 남깁니다

타입 우선 선언, 보이는 변수의 이름 가리기 금지, struct·enum 메서드, interface 계약, where 제약을 가진 타입 제네릭은 확정되어 있습니다. 제네릭 함수·오버로드·기본값 인수·이름 지정 인수, import 및 persist 초기화·종료 에도 이제 확정된 규칙이 있습니다. 타입을 명시한 지역 선언은 다음 검사 아래 초기값을 생략할 수 있습니다: 확정 초기화 검사. Async/GPU 함수 문법과 반환 참조의 명시적 수명 표기는 아직 미정입니다. 전체 문서는 다음을 참고하세요: 문법 개요 . 거부 예제는 표시된 확정 규칙만 설명합니다.

이어서 전체 자료형 문서 에서 값의 배치, 오류 래퍼, 소유권 컨테이너, CPU/GPU 계약을 확인하세요. 이 문서들은 언어 설계를 명세하며 컴파일러나 런타임의 실제 구현을 증명하지는 않습니다.
