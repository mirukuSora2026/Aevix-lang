  1. 01

    컴파일러 받기

    사용하는 플랫폼의 컴파일러 설치 파일을 0.2V 미리보기 에서 받고 설치 안내를 따르세요. 패키지는 Aevix 런타임을 포함하고 PATH를 등록합니다. 네이티브 컴파일에 필요한 Clang과 플랫폼 링커·SDK는 별도로 설치한 뒤 새 터미널을 여세요. VS Code 확장은 같은 릴리스 페이지에서 따로 받을 수 있습니다.

    패키지 파일명에는 0.2.0-dev표기를 유지합니다. macOS 패키지는 Apple Silicon과 macOS 26.0 이상이 필요합니다. Linux 패키지의 대상 환경은 Ubuntu 24.04/glibc 2.39이며, Windows x86-64 패키지는 실험 단계로 AOT만 지원합니다.

    소스 빌드: macOS ARM64 / Linux ARM64 또는 x86-64

    다음 절차는 Apple Silicon Mac과 ARM64 또는 x86-64 Linux 호스트를 대상으로 합니다.

    Git, CMake 3.20 이상, C 컴파일러, C++20 컴파일러를 설치하세요. 네이티브 실행에는 Clang, 링커, 플랫폼 C 런타임·SDK도 필요합니다. 이 빌드는 AOT를 사용하므로 LLVM 개발 라이브러리는 필요하지 않습니다.

    git clone https://github.com/mirukuSora2026/Aevix-lang.git
cd Aevix-lang
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DAEVIX_ENABLE_JIT=OFF
cmake --build build --config Release --parallel 2

    이 명령은 저장소의 현재 리비전을 빌드합니다. 지원 기능은 0.2 구현 프로필 에서, JIT 빌드 옵션은 README 에서 확인하세요.

    아래 명령은 설치되어 PATH에 등록된 aevixc 를 사용합니다. 소스에서 빌드했다면 ./build/aevixc 를 대신 사용하세요.

  2. 02

    파일 저장: hello.avx

    작업 디렉터리에 이 파일을 만드세요. 기본 정수 연산에는 import가 필요하지 않습니다.

    i32 square(i32 value) {
    return value * value;
}

i32 main() {
    return square(6) == 36 ? 0 : 1;
}
  3. 03

    검사하고 실행하기

    aevixc --check hello.avx
aevixc hello.avx
echo $?

    예상 종료 상태: 0. 이 예제는 아무것도 출력하지 않습니다. 첫 명령은 타입과 소유권을 검사합니다. 두 번째 명령은 프로그램을 컴파일하고 실행한 뒤 임시 실행 파일을 삭제합니다.

    Windows PowerShell에서는 다음 값으로 종료 상태를 확인합니다: $LASTEXITCODE. Visual Studio에서 소스를 빌드했다면 다음 경로를 사용합니다: .\build\Release\aevixc.exe. Windows 미리보기 패키지는 실험 단계입니다.
