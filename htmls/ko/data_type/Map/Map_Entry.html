1입니다. 진입 능력

Map.entry는 한 번 조회를 수행하고 특정 키에 대한 선형 기능을 반환합니다. 이 기능은 전체 맵, 트랙 점유 또는 빈 상태를 독점적으로 대여하고 터미널 작업이 어떤 일이 일어날지 선택할 때까지 들어오는 키를 소유합니다. 그것은 별도로 할당 된 key/value 컨테이너가 아니며지도를 초과 할 수 없습니다.

설계 초안. 이것은 Aevix 계약 제안이며 구현 주장이 아닙니다. 콜백, 반복자, 특성 및 오류 전달자 이름이 설명됩니다. 매개 변수 사용 T value 가치에 의하여, &T value 공유 대여, 그리고 &mut T value 단독 대여. 패스 소유자를 호출합니다 x, &x, 또는 &mut x; 복용 &mut owner 에는 mut 바인딩. 기존 참조 및 빌린된 보기는 직접 전달 됩니다. 콜백 별칭, 오류 레코드 및 반환 참조 수명 표기는 설계 설명으로 남아 있습니다. mut를 선언하지 않는 한 바인딩은 변경할 수 없으며 unit는 값 형식입니다.

2입니다. 저장된 키와 들어오는 키

점유된 엔트리의 경우, 원래의 저장된 키는 정규적으로 유지되지만 동일한 들어오는 키는 여전히 이 능력에 의해 소유될 수 있습니다. key는 이 상태에서 저장된 키를 노출시킵니다; into_incoming_key는 두 상태 중 하나에서 원래의 들어오는 키를 복구합니다. 사용되지 않은 진입 능력을 떨어뜨리면 들어오는 키가 파괴되고 대여이 해제됩니다. 저장된 키가 변경할 수 없습니다.

3입니다. 독점 범위

모든 입력 작업은 동일한 라이브 맵 임대가 필요합니다. 반환된 가변 값 참조는 리스를 확장하고 관련 없는 맵 변경가 끝날 때까지 이를 방지합니다. 콜백은 해당 값을 편집할 수 있지만 구조적으로 지도에 액세스하거나, 이스케이프 값 대여을 캡처하거나, 다른 별칭을 통해 다시 입력할 수 없습니다. Occupied/vacant 상태가 이 범위에서 다른 안전한 작성자와 경쟁할 수 없습니다.

4입니다. 복구 캐리어

EntryInputError에는 정지 라이브 입력 기능과 사용되지 않은 대체 값이 포함되어 있습니다. EntryBuildError에는 항목과 비행 전 오류 또는 콜백 오류가 포함되어 있습니다. 이 캐리어들은 핸들링 또는 드롭될 때까지 지도 대여을 유지한다. 할당된 프리플라이트 실패 시 어떠한 입력도 자동으로 파괴되지 않습니다. 일반적인 콜백 오류는 키를 비워둡니다; 콜백은 초기화된 캡처와 엔트리 리스를 해제합니다. 이 표기법은 레코드 구문을 수정하는 대신 오류 계약을 설명합니다.

5입니다. MapEntry 함수 참조

개념적 시그니처반환도메인, 소유권, 오류 및 비용
MapEntry.is_occupied(&MapEntry<K, V> entry)bool다른 해시 검색 없이 룩업 결과를 테스트합니다; O(1).
MapEntry.key(&MapEntry<K, V> entry)&K점유될 때 표준에 의하여 저장된 열쇠, 또는 빈 때 소유된 들어오는 열쇠를 빌리십시오; 수명은 입장 대여에 의해 바운스됩니다.
MapEntry.get(&MapEntry<K, V> entry)Optional<&V>점유 값 또는 return 없음; 할당 없음.
MapEntry.get_mut(&mut MapEntry<K, V> entry)Optional<&mut V>배타적으로 점유된 가치를 빌리십시오; 변하기 쉬워 열쇠는 드러내지 않습니다.
MapEntry.or_insert(MapEntry<K, V> entry, V value)Result<&mut V, EntryInputError<K, V>>Occupied: 사용되지 않는 들어오는 열쇠 및 가치, 그 후에 return에 의하여 저장된 변하기 쉬워 가치를 파괴하십시오. 프리플라이트(preflight) 및 삽입 실패는 진입 능력과 사용되지 않는 가치를 돌려보낸다.
MapEntry.or_insert_with(MapEntry<K, V> entry, Make<V> make)Result<&mut V, EntryBuildError<K, V, unit>>용량 사전 비행 후 빈 경우에만 원샷 빌더를 실행합니다. 사전 비행 실패는 달리기 없는 입장 기능을 만듭니다 돌려보냅니다; 콜백은 입장을 안전하게 풀어 놓습니다.
MapEntry.try_or_insert_with(MapEntry<K, V> entry, TryMake<V, E> make)Result<&mut V, EntryBuildError<K, V, E>>Vacant builder failure는 E 및 빈 항목 기능을 반환합니다. 값이 삽입되지 않습니다. 외부 콜백 부작용은 반전되지 않습니다.
MapEntry.insert(MapEntry<K, V> entry, V value)Result<Optional<V>, EntryInputError<K, V>>점유된 값을 바꾸거나 빈 값을 삽입합니다. return 이전 값이 있을 때. 실패는 입구와 사용되지 않는 보충을 재기한다.
MapEntry.and_modify(MapEntry<K, V> entry, Mutate<V> update)MapEntry<K, V>점유되었을 때만 동기 콜백을 한 번만 실행하십시오. return 다음 선택을 위해 항목. 콜백은 보호된 가변 참조를 유지할 수 없습니다.
MapEntry.remove(MapEntry<K, V> entry)Optional<V>점유: 값을 제거하고, 저장 및 사용되지 않는 수신 키를 파괴하고, return V. 빈 공간: 들어오는 키와 return None을 파괴합니다.
MapEntry.remove_entry(MapEntry<K, V> entry)Optional<(K, V)>return는 key/value 소유자를 저장하고 사용되지 않는 들어오는 키를 파괴한다. 빈 공간: 들어오는 키와 return None을 파괴합니다.
MapEntry.into_incoming_key(MapEntry<K, V> entry)K맵 임대를 해제하고 두 상태 모두에서 원래 들어오는 키를 복구하여 저장된 항목을 변경하지 않고 그대로 둡니다. O(1).

6입니다. 게으른 가치 건설

게으른 빌더는 빈 항목에 대해서만 실행되므로 점유된 액세스는 사용되지 않은 대체 값을 할당하지 않습니다. 비행능력이 가장 먼저 발생한다. 빌더는 자체 return 유형에 따라 할당하거나 실패할 수 있으며, 성공적인 빌더는 삽입을 위해 한 명의 소유자를 생성합니다. 이 항목 API는 동기식이며 never는 맵의 가변 기능을 유지하면서 일시 중지됩니다.
