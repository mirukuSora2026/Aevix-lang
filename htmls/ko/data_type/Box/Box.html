1입니다. 고유한 초기화된 Heap 소유권

0.2 구현 범위. Box prelude에 없는 것: use import memory { Box };. 구현된 기능들은 Box.new, Box.into_dyn, Box.as_ref 및 Box.as_mut. 새로운 반환 Result<Box<T>, InputError<T>>InputError는 코어에 의해 공급되고 메모리에 의해 재수출됩니다. 동적 변환은 할당하지 않고 기존 콘크리트 소유자를 이동합니다. 카탈로그에 있는 Box slice/clone/extraction/FFI 채용 API는 계획안을 남아 있습니다. 자세히 보기 0.2 구현 프로필; 나머지 카탈로그 항목은 설계 계약입니다.

Box<T>는 하나의 초기화된 T 및 관련 할당을 고유하게 소유합니다. 상자 이동은 소유권을 이전하며, T를 복제하거나 할당을 공유 저장소로 전환하지 않습니다. 일반 파괴는 T의 마무리를 실행하고 스토리지와 일치하는 릴리스. 논리적 소유권 및 소멸자 의무는 실제 상태로 유지되는 동안 제로 크기 페이로드에 대한 할당은 부재할 수 있습니다. 상자는 원시 주소가 아니며 자동으로 고정되는 자체 참조 값을 만들지 않습니다.

설계 초안. 함수, 특성, 오류 캐리어 및 콜백 표기법은 API가 아닌 의도된 계약을 지정합니다. 변수와 매개 변수는 첫 번째 유형이며 바인딩은 기본적으로 변경할 수 없습니다. 매개 변수 사용 T value 가치에 의하여, &T value 공유 대여, 그리고 &mut T value 단독 대여. 패스 소유자를 호출합니다 x, &x, 또는 &mut x; 복용 &mut owner 에는 mut 바인딩. 기존 참조 및 빌린된 보기는 직접 전달 됩니다. 콜백 별칭, 오류 레코드 및 반환 참조 수명 표기법은 설계 설명으로 남아 있습니다. unit는 return 위치 void와는 다른 값 유형입니다.

2입니다. 오류 가 있는 건축 과 복구

할당은 값 설치 전에 기본 레이아웃, 정렬 및 대상 개체 경계를 확인합니다. T를 사용하는 생성자는 반환된 프리플라이트 실패에 대해 사용되지 않은 입력을 반환합니다. Builder 양식이 먼저 예약되고 Builder를 정확히 한 번 호출합니다. 실패 가능한 builder가 실패하면 초기화된 출력만 완료됩니다. 이것은 외부 콜백 효과를 반전 시키거나 프로세스 종료에서 복구 할 수있는 약속이 아닙니다. 생성자는 초기화되지 않은 메모리를 안전한 T 값으로 노출하지 않습니다.

3입니다. 대여 및 이동

읽기 권한은 다른 읽기 권한과 공존할 수 있으며, 쓰기 권한은 한 가지만 필요합니다. 대여은 소유자의 수명 및 관련 초기화 된 가치와 관련이 있습니다. 박스 핸들을 이동하는 것이 힙 페이로드를 물리적으로 이동시키지는 않지만, 언어는 여전히 라이브 대여과 충돌하는 소유자 작업을 거부합니다. T를 대체하거나 추출하는 것은 그 값을 이동시킬 수 있다. 코드가 더 강력한 주소 안정성 보장에 의존할 때 별도로 지정된 고정 추상화를 사용합니다.

선택된 동적 인터페이스 통합. Box<dyn Interface> 콘크리트 페이로드를 소유하고 명시적 Box.into_dyn 변환을 지원합니다. 적격한 대여 방법에 대한 호출은 자동 페이로드 액세스 및 대여과 함께 owner.method(...)를 사용할 수 있습니다. Box.as_ref(&owner) 및 Box.as_mut(&mut owner)는 명시적인 보기를 노출합니다. 소유권 및 독점 액세스는 checked로 유지됩니다. Box.into_inner를 통한 값 자체 추출, 이름 충돌 및 동적 페이로드 추출은 열려 있습니다. Box.new 할당 결과는 여전히 명시적으로 처리되어야 합니다.

4입니다. Copy, 복제 및 매핑

Copy 및 Clone은 암시적 상자 복제가 아닌 포인트리 연산을 설명합니다. 두 명시적 복제 호출 모두 별도의 고유 저장소를 할당합니다. 복제된 T는 Shared 핸들을 포함할 수 있으므로 복제가 깊은 격리를 의미하지는 않습니다. 매핑은 소유자 반환 할당 오류를 약속할 때 복구 가능한 소스를 사용하기 전에 미리 할당해야 합니다. T를 소비하고 실패하는 콜백은 다른 오류 캐리어를 가지며 원래 T를 정직하게 약속 할 수 없습니다.

5입니다. 파괴, 자원 및 스레드

일반 소유 드롭은 런타임의 종료 정책에 따라 초기화된 페이로드를 정확히 한 번 파괴합니다. 이는 절대 누출 방지가 아닙니다: 의도적으로 도달할 수 없는 소유권, 프로세스 종료 또는 유출된 주변 그래프는 리소스 정리를 방지할 수 있습니다. 다른 호스트 스레드로 전송하려면 T: 보내기가 필요합니다. 공유 읽기 참조에는 T: 동기화가 필요합니다. 이러한 이름은 안전 특성을 설명하지만 임의의 외국 자원이 스레드와 호환된다는 보장은 아닙니다. GPU 액세스에는 별도의 배치 및 완료 계약이 필요합니다.

6입니다. 전체 제안 Box API

모든 잘못된 할당 경로가 return 명시적 오류 이하. InputError 및 OwnerError는 문서화된 사전 비행 실패에 대한 이동된 입력을 유지합니다. By-value owning arguments move, Copy arguments copy 및 reference arguments borrow; 반환 된 참조는 소스 대여에 의해 제한됩니다. 복잡성에는 모든 pointee 작업을 하나의 명령으로 취급하는 대신 T 크기의 이동, Clone, Drop, 비교 및 콜백이 포함됩니다.

Box.from_fn(T, Make<T> make)Result<Box<T>, CollectionError>원샷 생성자를 호출하기 전에 예약합니다; 큰 임시가 필요하지 않습니다.

7입니다. 배열과 외부 인터페이스

Array가 포함된 상자는 해당 배열의 인라인 요소를 소유하고, Vector가 포함된 상자는 벡터 핸들을 소유하며, 버퍼는 Vector 규칙을 따릅니다. Slice가 포함된 상자는 빌린 설명자만 소유하고 참조자를 취득하지 않습니다. 더 보기 박스형 배열과 뷰. 외국 입양 및 석방에는 할당자, 수명 및 완결 계약이 필요합니다. Box 또는 FFI 안전한 생성자 외부에서 확인되지 않은 채택을 명시적으로 유지합니다.

8입니다. 예제 및 관련 소유자

카탈로그 예제. 이 프래그먼트는 또한 스코프 노트에서 식별된 제안된 함수를 사용한다; 완전한 0.2 프로그램이 아니다.

Result<Box<i32>, InputError<i32>> value = Box.new(42);
Box.payload_size(i32);
Box.payload_alignment(i32);

그 결과 Ok 브랜치는 새 박스를 소유하게 되고, Err 브랜치는 거부된 입력을 소유하게 된다. 선택한 차입, 소유권 및 열거형 분기 구문은 다음을 참조하십시오. 문법 참조. 다른 기능별 API 구문은 초안으로 남아 있습니다. 더 보기 Shared 소유권 재분배 및 Vector Growable 저장을 위해. 주 참조는 이 독립적인 제안을 알린다; 할당자 구현 또는 물리적 ABI는 주장되지 않는다.
