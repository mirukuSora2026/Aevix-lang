1입니다. 안전한 Box는 외국 포인터 계약이 아닙니다.

주소만으로는 Box 소유자를 설정하지 않습니다. 외래 메모리는 다른 할당자, 표현, 정렬 또는 파괴 프로토콜을 사용할 수 있습니다. 안전한 Box 생성자는 임의의 주소를 자동으로 채택하거나 C 할당에 유효한 T가 포함되어 있는 척하지 않습니다. 미래의 모든 채택 인터페이스는 문서화 된 증거 의무가있는 별도의 안전하지 않거나 감사 된 FFI 시설입니다.

2입니다. 크기, 정렬 및 유효한 값

어댑터는 대상 크기, 필수 정렬, 초기화된 바이트, 유효한 판별값 및 중첩된 소유권 또는 참조 불변 값을 설정해야 합니다. 동등한 byte 너비는 호환성에 충분하지 않습니다. byte 버퍼는 임의의 T의 유효한 값을 포함하지 않고 원시 표현을 전달할 수 있습니다. 기본 필드 레이아웃 및 패딩은 휴대용 와이어 형식이 아닙니다. 명시적 사용 Byte 코덱 값을 직렬화할 때.

3입니다. 일치 할당 및 Deallocation

할당 및 릴리스는 할당자 ID, 정확한 할당 기반, 레이아웃 및 소유권 count에 동의해야 합니다. 내부 포인터를 채택하거나 동일한 할당을 두 번 해제하는 것은 어댑터 계약을 위반하는 것입니다. 외부 릴리스 콜백에는 일반적인 Box 소멸자가 추론할 수 없는 스레드 선호도 또는 런타임 요구 사항이 있을 수 있습니다. 스레드 간에 핸들을 이동하는 것은 전체 리소스 계약이 이를 지원하는 경우에만 허용됩니다.

4입니다. 외국 대여은 시간이 필요합니다.

빌린 수출은 소유권을 양도하지 않습니다. 외국 측은 대여이 끝나기 전에 읽거나 쓰는 것을 중단해야하며 소유자는 필요에 따라 살아 있고 수정되지 않은 채로 있어야합니다. 읽기 내보내기는 대여 시 외부 변경를 금지합니다. 쓰기 가능한 내보내기는 모든 충돌하는 별칭을 제외합니다. 만약 외국 콜백이 나중을 위해 주소를 저장한다면, 동기 호출 경계는 충분한 수명 증명이 아니다.

5입니다. 비동기 유지 및 완료

지연된 외국 작업의 경우 실제 소유자를 완료 관리 어댑터로 이동하거나 선택적 사용자 핸들과 독립적으로 완료를 추적하는 구조화된 범위를 사용합니다. 요청을 취소해도 외국 작업이 중지되었음을 증명하지 않습니다. 알림 토큰을 삭제하거나 유출하는 것은 빌린 메모리의 조기 릴리스를 허용할 수 없습니다. 장치 완성 및 호스트 가시성에는 서로 다른 동기화 단계가 필요할 수도 있습니다.

6입니다. 실패와 부분적인 입양

사전 비행 실패는 원래 소유자에게 발신자를 남깁니다. 외부 라이브러리가 소유권을 갖게 되면, 어댑터는 소유자가 return를 파괴하거나 다른 리소스 레코드로 전송하는 오류를 명시해야 합니다. 외국 릴리스 콜백을 실행할 수 있고 return를 손상되지 않은 Box로 실행할 수 있는 API를 피하십시오. 오류와 풀림은 모든 초기화된 리소스에 대해 하나의 명확한 소유자를 유지해야 합니다.

7입니다. 제외된 단축키 및 관련 참조

이 페이지는 from_raw 또는 임의의 set-initialized-length 단축키를 의도적으로 정의하지 않습니다. 일반 Box API 건설현장에서도 안전이 보장됩니다. Shared 스레드 경계 및 Slice 관련된 제한사항을 설명합니다. 문서화된 FFI 계약은 무엇이 감사되어야 하는지를 식별한다; 성공적인 빌드나 포인터 크기의 래퍼는 외부 구현을 검증하지 않는다.

네이티브 할당 및 크기 메타데이터는 이 소유자를 외부 할당자에게 전송하거나 와이어 표현을 정의하지 않습니다. 

Result<Box<i32>, InputError<i32>> native_owner = Box.new(42);
usize payload_bytes = Box.payload_size(i32);
