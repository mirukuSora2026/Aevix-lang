1입니다. 개요

0.3 컴파일러는 대여한 Range의 start/end/step_magnitude/step/is_inclusive/is_descending/is_empty 조회를 제공합니다. 조회는 설명자를 소비하거나 반복을 진행시키지 않습니다. 간격은 부호 없는 크기이며 방향은 별개입니다. Range 반복이 비어 있는지와 버퍼 API의 범위 정책은 구분합니다. bytes.copy_within은 해당 오름차순 반복자가 비어 있더라도 뒤집힌 원본 끝점을 거부합니다.

0.2 구현 범위. Range<T> 는 i128/u128을 포함해 지원하는 정수 기본 타입에 import 없이 사용할 수 있습니다. 구현된 생성자는 new, closed, descending 및 descending_closed; 0..10 및 0..=10 는 오름차순 형식의 축약 표기입니다. Range.with_step(range, magnitude) 및 Range.len(&range) 는 구현된 다음 오류를 담은 Result를 반환합니다: RangeError.InvalidStep/CountOverflow . 다른 조회·반복자 객체·컬렉션 생성 보조 함수는 아직 제안입니다. 자세한 내용: 0.2 구현 프로필; 나머지 카탈로그 항목은 설계 계약입니다.

카탈로그 상태. 지원 범위 알림은 구현된 부분집합을 밝히며 다른 API는 제안된 Aevix 계약입니다. 선택된 매개변수 형식: T value, &T value, 및 &mut T value. 타입 팩·호출 가능 타입·반환 참조의 명시적 수명 표기·오류 enum은 표시된 곳에서 설명용으로 남습니다. 모든 연산은 네임스페이스 함수를 사용하며 값 메서드 별칭은 없습니다.

Range는 소유하지 않는 값 설명자입니다. 할당된 컨테이너나 컬렉션의 대여가 아닙니다. 선택된 범위 리터럴 0..10 은 다음과 같은 설명자를 만듭니다: Range.new(0, 10)동안 0..=10 에 대응하는 설명자: Range.closed(0, 10). 리터럴과 기존 Range 값 모두 범위 형식의 for에서 사용할 수 있습니다. 자세한 내용: 반복문. 이 첫 설계는 정수 기본 타입과 대상 크기 정수를 지원합니다. 부동소수점 범위·유니코드 순회·끝이 없는 경계·임의의 사용자 정의 간격에는 별도 계약이 필요합니다.

2입니다. 경계 및 선언

Range.new(start, end) 는 start를 포함하고 end를 제외합니다. 닫힌 생성자는 도달 가능한 end 값을 포함합니다. 내림차순 생성자는 부호와 독립적으로 방향을 표현하므로 부호 없는 카운트다운에 음의 부호 없는 정수가 필요하지 않습니다. 

Range<i32> indices = Range.new(0, 5);
Range<i32> closed = Range.closed(0, 5);
u8 countdown_start = 3;
u8 countdown_end = 0;
Range<u8> countdown = Range.descending_closed(countdown_start, countdown_end);

3입니다. Stepping 및 정확한 멤버십

간격의 크기는 T와 같은 폭의 부호 없는 U이며 반드시 양수여야 합니다. 시작 0, 끝 6 포함, 간격 크기 4이면 결과는 0과 4입니다. 6은 포함 가능한 경계이지만 도달할 수 없습니다. contains는 경계뿐 아니라 간격도 검사합니다.

방향과 반대인 시작·끝 쌍은 빈 범위이며 자동 정규화하지 않습니다. 마지막 유효 값 뒤로 진행할 때는 검사된 비교로 종료합니다. 종료를 알아내기 위해 오버플로하는 증가 연산을 수행하지 않습니다.

4입니다. 카디널리티 및 목표 범위

표현 가능한 두 끝점으로 usize가 셀 수 있는 것보다 많은 값을 나타낼 수 있습니다. 전체 닫힌 u64 영역에는 2^64개 값이 있으므로 64비트 usize도 길이를 표현할 수 없습니다. 이때 Range.len은 CountOverflow를 반환하지만 설명자와 독립적으로 진행하는 반복자는 여전히 의미가 있습니다.

부호 있는 최솟값부터 최댓값까지의 거리도 검사된 중간값이나 충분히 넓은 중간값으로 계산합니다. 먼저 T 안에서 끝점을 빼 오버플로해서는 안 됩니다. 컬렉션 생성은 추가로 바이트 크기·주소 공간·할당자 한계를 검증합니다.

5입니다. 값 의미론과 반복자 상태

정수 범위 설명자는 소유 할당이 없는 Copy 값입니다. 반복자를 만들면 별도 커서 상태를 생성합니다. 반복자 하나를 소비한다고 설명자의 다른 복사본이 몰래 변경되지는 않습니다. Range.end는 경계이고 Range.last는 실제 마지막 요소입니다.

take·skip·split·reverse는 문서화된 수열을 보존하면서 끝점 표기를 정규화할 수 있습니다. Range.equal은 설명자 필드를 비교합니다. Range.sequence_equal은 빈 수열·원소 하나의 수열을 표기보다 수열의 의미로 비교합니다.

6입니다. 함수 참조

T value 는 값을 전달합니다. Copy 타입은 복사하며 소유 non-Copy 값은 깊은 clone 없이 이동합니다. &T value 는 공유 읽기 대여이고 &mut T value 는 배타적 변경 대여입니다. 호출 시 각각 x, &x, 또는 &mut x 를 사용합니다. 이미 대여한 참조·뷰 값은 직접 전달하며 &를 하나 더 붙이면 타입이 바뀝니다. *ref 는 참조 대상을 읽고 씁니다. 일반적인 &mut x 에는 mut 소유자가 필요합니다. mut T value 만으로는 값 매개변수가 함수 안에서 변경 가능해질 뿐 호출자의 값을 변경하지 않습니다. 겹치는 활성 대여는 마지막 사용까지 검사합니다. 서로 겹치지 않는 영역은 안전하게 나눌 수 있으며 대여는 원본보다 오래 살 수 없습니다. 동기화된 내부 변경은 해당 타입의 계약을 따릅니다. Fn(A) -> B 는 호출 가능한 값을 설명하며 반환 참조의 수명 관계는 본문으로 문서화합니다.

U 는 T와 비트 폭이 같은 부호 없는 정수를 뜻합니다. RangeDirection, RangeError, 및 RangeIterator<T> 는 제안된 라이브러리 보조 타입이며 추가 수치 기본 타입이 아닙니다.

7입니다. 범위 및 컬렉션 색인

숫자 Range 자체는 소유자 접근 권한이 아닙니다. 컬렉션 슬라이싱은 현재 길이에 대해 경계를 따로 검사하고 수명을 검사한 Slice·MutSlice를 만듭니다. 간격이 1보다 크면 연속 Slice가 아닙니다. 반복자나 명시적인 strided 뷰를 사용하세요.

인덱스는 바이트·유니코드 자소 군집이 아니라 요소를 셉니다. usize Range는 컬렉션 위치를 표현할 수 있지만 i32 Range를 암시적으로 변환하지는 않습니다. 음수·오버플로 변환은 명시적으로 실패합니다.

8입니다. 오류 값 및 구체화

구현된 RangeError variant는 InvalidStep 및 CountOverflow. StepOverflow, OutOfBounds 및 LengthMismatch 는 제안된 추가 범위 연산용이며 0.2 enum에는 포함되지 않습니다. 실패하지 않는 설명자 생성은 반대 경계를 빈 수열로 허용합니다. 실제 컬렉션 생성은 크기·할당 실패를 보존하는 CollectionError를 사용합니다.

오류 반환 시 부분 초기화된 Array·Vector가 보이면 안 됩니다. 향후 확장에서 요소 생성 실패 전에 앞부분을 초기화했다면 안전하게 정리해야 합니다. 현재 정수 수열 자체에는 실패 가능한 요소 콜백이 없습니다.

9입니다. 병렬 파티셔닝 및 장치

유한 정수 설명자는 CPU나 지원되는 GPU 작업으로 복사할 수 있지만 호스트에서 수집했다고 데이터가 GPU에 놓이지는 않습니다. 병렬 분할은 순번을 겹침·누락 없이 나누고 경계 산술을 검사해야 합니다.

서로 겹치지 않는 인덱스의 범위만으로 메모리 대여도 겹치지 않는다고 증명할 수는 없습니다. 대여를 만드는 컬렉션 API가 실제 영역을 검증하고 기록합니다. 축약 순서·정수 오버플로·재현성은 연산 계약을 따릅니다.

10입니다. 예제 및 경계 사례 

Result<Range<i32>, RangeError> strided = Range.with_step(Range.closed(0, 6), 4);
u64 smallest = 0;
u64 largest = 18446744073709551615;
Range<u64> full = Range.closed(smallest, largest);
Result<usize, RangeError> too_many = Range.len(&full);
Optional<u8> last = Range.last(&countdown);
Result<Vector<i32>, CollectionError> values = Range.collect_vector(indices);

전체 영역의 개수는 지원하는 64비트 ARM64·x86-64 대상의 usize를 초과하므로 실패합니다. 부호 없는 내림차순 범위는 255로 순환하지 않고 0에서 끝납니다. 타입 우선 선언은 큰 리터럴 각각에 명시적인 정수 문맥을 제공합니다.
