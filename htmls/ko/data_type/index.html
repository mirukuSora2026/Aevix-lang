구현된 타입과 설계 카탈로그

현재 0.2 프로필 이 실행 가능한 기능의 기준입니다. 타입이 기본 환경에 있다고 해서 그 카탈로그의 모든 함수를 사용할 수 있는 것은 아닙니다. Copy 및 정적 Fn/FnMut/FnOnce 계약과 구현된 핵심 오류 enum도 자동으로 제공됩니다.

계열0.2 범위와 import
숫자 스칼라, bool, char, byte, unit, never내장 값입니다. int = i32, float = f64입니다. Integer·Float 변환의 일부, Byte.from_u8/to_u8, Unit.value, Never.unreachable은 구현되어 있습니다. 카탈로그의 파싱·형식화·일반 수학 보조 함수는 아직 제안입니다.
string, string_view, Array, Vector, Slice, MutSlice, Tuple, Range, Optional, Result일부 기능이 구현된 기본 제공 타입입니다. 각 대표 페이지에 실제 호출을 표시합니다. 자동 제공이 전체 API 카탈로그의 지원을 뜻하지는 않습니다.
Boximport memory { Box }; 로 할당·뷰·소유 dyn 변환을 사용합니다.
Complex / complex, Simd / SimdMask명시적 complex 및 simd import가 필요합니다. 다음 문서에서 Complex 구현 프로필 및 SIMD 구현 프로필 지원 연산을 확인하세요.
Map, Set, Shared, Weak, Atomic, Mutex, RwLock, Tensor, Quantized, Task, Pending0.2와 기본 제공 범위에 포함되지 않는 전문 라이브러리 설계입니다. 미래의 import 경로나 카탈로그 시그니처가 현재 컴파일러·런타임 지원을 증명하지는 않습니다. CPU parallel.for_each는 제안된 Task API와 별개입니다.

새로운 0.3 편의 기능인 Boolean.to_integer, 정수 반환의 bool 변환, raw string, 출력 조합은 예정된 작업이며 0.2 소스 규칙을 바꾸지 않습니다.

확정된 언어 규칙

확정된 선언 규칙. 타입 우선: i32 size = 128;. 기본적으로 불변이며 다음 형태는 mut i32 count = 0; 가변 바인딩에 사용합니다. rsn 은 다음과 같이 정적 추론을 요청합니다: rsn size = 128;. 추론된 타입은 고정됩니다. 제약 없는 정수·실수 리터럴의 기본형은 i32·f64입니다. const i32 LIMIT = 100; 는 불변 컴파일 타임 상수를 선언하며 const rsn SCALE = 2.0; 은 그 고정 타입을 추론합니다. const와 mut의 조합은 잘못된 코드입니다. 일반 불변 바인딩은 실행 중에 초기화할 수 있습니다. 선택된 다음 persist 키워드는 선언별 프로세스 수명 저장소를 나타냅니다. 모듈 값은 진입 전에, 지역 값은 처음 도달했을 때 초기화하며 제네릭 지역 저장소는 구체 타입 인수 조합마다 나뉩니다. 같은 선언·구체 인수에 대한 AOT·JIT 코드 버전은 저장소를 공유합니다. 정상 종료에서는 추적된 자원 사용을 마친 뒤 초기화 완료의 역순으로 성공한 값을 정리합니다. 정리 중 다른 persist에는 접근할 수 없습니다. 자세한 내용은 저장소 식별, 초기화, 및 정상 종료 에 확정된 규칙이 있습니다. 이는 선택된 저장소 계약이며 다음 0.2 프로필 은 구현된 persist 동작의 범위를 정합니다. 스레드별 저장소, 제네릭 타입 멤버 persist, 사용자 정의 정리 구문은 별도의 미정 사항입니다. 디스크에 데이터를 보존하거나 정적 타입 멤버를 뜻하지 않습니다.

확정된 기본 제공 환경. 선택된 정수·부동소수점 스칼라 타입과 다음 int/float 별칭, bool, char, byte, unit, 및 never 는 자동으로 제공됩니다. void 는 반환 위치 표시로 유지됩니다. 기본 환경은 다음 타입도 제공합니다: string, string_view, Array, Vector, Slice, MutSlice, Tuple, Range, Optional, 및 Result. 자동 제공이 컴파일러 원시 타입임을 뜻하지는 않습니다. 다른 라이브러리 타입에는 다음처럼 명시적 import가 필요합니다: import tensor { Tensor };. 카탈로그에 있다는 이유만으로 사용할 수는 없습니다. 자세한 내용은 확정된 기본 제공·import 경계.

확정된 매개변수 규칙. T value 는 값으로 전달합니다. Copy 타입은 복사하고 소유한 non-Copy 값은 암묵적인 깊은 복사 없이 이동합니다. &T value 는 공유 읽기 대여이고 &mut T value 는 독점 수정 대여입니다. 호출에서는 다음을 명시적으로 전달합니다: x, &x, 또는 &mut x. 이미 대여한 참조나 다음과 같은 뷰 값은 Slice<T>, MutSlice<T>, 또는 string_view &를 더하지 않고 그대로 전달합니다. *ref 는 참조 대상에 접근합니다. 일반 가변 대여에는 다음과 같은 mut 소유 바인딩이 필요합니다. 다음 mut T value 매개변수는 값으로 받은 함수 내부 지역 바인딩만 가변으로 만들고 &mut T value 는 호출자의 원본 수정을 허용합니다. 활성 대여 충돌은 마지막 사용까지 겹치는 메모리 영역으로 검사하므로 분리가 증명된 영역은 허용합니다. 어떤 대여도 원본보다 오래 살 수 없습니다. 내부 동기화 수정은 각 타입 계약을 따릅니다. 반환 참조의 명시적 수명 표기는 검토 중입니다.

확정된 반환 규칙. non-void 함수의 일반 반환은 값을 명시적으로 반환합니다. Result 반환 함수는 다음 후위 연산자를 추가로 사용할 수 있습니다: ? . 이를 통해 같은 오류형의 Err를 명시적으로 전파합니다. 성공 반환에는 여전히 다음을 씁니다: return. 마지막 표현식을 암묵적으로 반환하지 않습니다. unit 반환 함수도 unit 값을 명시적으로 반환합니다. 반환 위치의 void는 본문 끝까지 진행하거나 값 없는 return을 허용하며, 발산 경로에는 불가능한 반환을 요구하지 않습니다.

비용과 안전성. 소유 컨테이너는 기본적으로 이동합니다. clone·할당·디바이스 전송·비동기 완료는 명시적입니다. 대여한 뷰의 원본 소유 값은 모든 사용 동안 유효해야 하고 가변 뷰는 독점 접근이 필요합니다. 구현된 일반 정수 연산자의 실패는 최적화 빌드에서도 안전하게 실행을 중단합니다. 선택된 다음 checked(expression) 형태와 일반적인 이름 있는 checked 산술 카탈로그는 설계상 명시적인 다음 Result 값을 반환하지만 0.2에는 구현되어 있지 않습니다. 구현된 숫자 변환의 Result는 별도 연산입니다. 자세한 내용은 검사 산술. 초안 표시는 제안된 카탈로그 시그니처와 정말 미정인 항목에 적용되며, 확정된 실패 정책에 붙는 것이 아닙니다.

확정된 제어 흐름·스코프 규칙. if 및 while 에는 괄호로 감싼 bool 조건이 필요합니다. 실행 가능한 본문 문장 하나는 중괄호를 생략할 수 있지만 선언 본문에는 명시적 블록이 필요합니다. 다음 else 는 가장 가까운 짝 없는 다음 문장에 연결됩니다: if. 자세한 내용은 문장 본문 파싱. 세 가지 for 형태는 Range 값, C 방식 제어, 향상된 순회를 지원합니다. switch의 case는 끝에 명시적인 다음을 요구합니다: break;. 지역 변수는 렉시컬 스코프를 가지며 보이는 변수 이름을 가릴 수 없습니다. 모듈·타입 선언에는 다음을 지원하고 public/private, 정상 스코프 종료에서는 초기화 역순으로 현재 소유 값을 정리합니다. 전체 규칙·문서 태그·미정 범위는 다음에 있습니다: 문법 문서.

확정된 사용자 정의 타입 규칙. 구조체 는 접근 검사를 거치는 이름 지정 필드 초기화, 기본 private 필드, 타입이 있는 self 메서드, 명시적 타입 팩토리를 사용합니다. struct와 다음 enum 은 기본적으로 이동하며 모든 필드가 자격을 갖추면 Copy를 명시적으로 구현할 수 있습니다. enum 항목 이름은 기본 public이고 페이로드 필드는 기본 private입니다. 인터페이스 는 여러 계약 구현, 기본 메서드, 기본 구현 교체 시 필수 override, 기본 정적 디스패치와 명시적 dyn 뷰 또는 Box<dyn Interface> 소유권을 지원합니다. 제네릭 타입 은 <T>와 where T implements Copy를 사용합니다. 매개변수 제약이 컨테이너를 자동으로 Copy로 표시하지는 않습니다. 각 case/default는 독립 스코프를 가지며 enum switch는 모든 항목을 처리하거나 default를 제공해야 합니다.
