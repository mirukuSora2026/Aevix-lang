1. Set 집합 연산

관계는 회원 질문에 대답; 게으른 대수 반복자는 새로운 회원을 소유하지 않고 선택을 설명합니다. 소유된 구체화는 별도로 복사 또는 복제로 명명되며 Result를 반환합니다. 따라서 동일한 수학적 연산은 할당, 복제 또는 소유권 이전을 숨기지 않습니다. Set.equal는 여기에서 재정의되지 않고 공통 세트 페이지에 남아 있습니다.

설계 초안. 함수 이름, 콜백, 반복자, 특성 및 오류 캐리어는 제안된 Aevix 계약을 정의합니다. 매개 변수 사용 T value 가치에 의하여, &T value 공유 대여, 그리고 &mut T value 단독 대여. 패스 소유자를 호출합니다 x, &x, 또는 &mut x; 복용 &mut owner 에는 mut 바인딩. 기존 참조 및 빌린된 보기는 직접 전달 됩니다. 콜백 별칭, 오류 레코드 및 반환 참조 수명 표기는 설계 설명으로 남아 있습니다. mut를 선언하지 않는 한 바인딩은 변경할 수 없으며 unit는 값 형식입니다. 어떤 구현 또는 장치 지원 청구는이 카탈로그에서 다음과 같습니다.

2입니다. 평등과 질서의 조화

두 해시 세트 모두 씨앗이 다르더라도 동일한 멤버 등가 관계를 구현해야 합니다. 각 조회는 queried set의 자체 해시 정책을 사용합니다. 순서한 세트는 안정적인 전체 순서에 동의해야합니다. 일관성 없는 정책을 결합하는 것은 논리적 오류이지 메모리 안전하지 않음에 대한 라이선스가 아닙니다. 세트는 다중 세트가 아닙니다; 중복 카운트와 원래의 삽입 위치는 이러한 관계에 영향을 주지 않습니다.

3입니다. 빌린 iterators 및 대표

게으른 대수는 이터레이터와 모든 항복 참조가 해제 될 때까지 두 입력을 대여합니다. 어느 입력도 다른 별칭을 통해 구조적으로 수정될 수 없습니다. 노동 조합과 교차 계약은 의도적으로 동등한 클래스에 대한 왼쪽 저장된 대표를 선호; 따라서 평등에서 제외 된 메타 데이터는 예측 가능하게 선택 될 수 있습니다. 해시 반복 순서는 그 대표적인 선택에도 불구하고 지정되지 않은 상태로 유지됩니다. 이터레이터는 소스 소유자의 수명을 연장하지 않습니다.

5입니다. 정렬된 집합 대수 함수

개념적 시그니처반환도메인, 소유권, 오류 및 비용
OrderedSet.is_disjoint(&OrderedSet<T> a, &OrderedSet<T> b)bool호환 정렬 주문을 병합하고 동일한 쌍에서 중지; O(n + m) 비교 상한.
OrderedSet.is_subset(&OrderedSet<T> a, &OrderedSet<T> b)bool정렬된 병합 멤버쉽, 카디널리티는 초기에 거부할 수 있습니다. O(n + m) 비교 상한.
OrderedSet.is_superset(&OrderedSet<T> a, &OrderedSet<T> b)bool역 부분집합 관계; O(n + m) 비교 상한.
OrderedSet.union(&OrderedSet<T> a, &OrderedSet<T> b)DoubleEndedIterator<&T>정렬된 멤버를 병합합니다. 이에 상응하는 경우 대표를 선호합니다. 둘 다 빌려옴; O(n + m) 총 횡단 플러스 비교.
OrderedSet.intersection(&OrderedSet<T> a, &OrderedSet<T> b)DoubleEndedIterator<&T>대표자를 사용하여 정렬 된 공통 클래스; 둘 다 빌려; O(n + m) 총 비교 상한.
OrderedSet.difference(&OrderedSet<T> a, &OrderedSet<T> b)DoubleEndedIterator<&T>정렬 된 a-only 클래스; 둘 다 빌려, O(n + m) 총 비교 상한.
OrderedSet.symmetric_difference(&OrderedSet<T> a, &OrderedSet<T> b)DoubleEndedIterator<&T>정확히 하나의 입력에서 발견되는 정렬 된 클래스; O(n + m) 총 비교 상한.

이 일곱 가지 명령은 병합 견해와 관계입니다. 주문 출력은 OrderedSet.from_values 또는 애플리케이션 제어 삽입을 통해 명시적으로 빌드됩니다. 숨겨진 클론 또는 일반 컬렉션 변환은 암시되지 않습니다. 이중 종단 횡단은 왼쪽 대표 선호를 일관되게 존중해야합니다.

6입니다. 재료화 및 비용

*_copy 패밀리는 Copy 멤버에게만 사용할 수 있습니다. *_clone은 멤버의 잘못된 클론 계약을 호출합니다. CollectionError에는 이러한 변형에 대한 복제 실패가 포함됩니다. Result 구성은 선택한 각 소유자를 한 번 초기화하고 실패 시 부분 출력을 정리하며 두 입력을 변경하지 않습니다. 게으른 반복자는 결과 버킷을 할당하지 않지만 사용자 해싱, 평등, 비교 및 캡처 상태는 자체 비용을 가질 수 있습니다. 최악의 경우 해시 회원은 전체 대수 연산 이차 만들 수 있습니다. 정렬 된 병합 작업은 두 길이와 비교기 비용에서 선형입니다.

7입니다. 예 및 관련 소유권 

OrderedSet<i32> left = OrderedSet.new(i32);
OrderedSet<i32> right = OrderedSet.new(i32);
bool separate = OrderedSet.is_disjoint(&left, &right);
DoubleEndedIterator<&i32> merged = OrderedSet.union(&left, &right);

빈 집합은 관계를 true로 만들고 반복자는 empty로 만듭니다. 두 소스 소유자 모두 병합된 뷰를 위해 살아 있습니다. populated set의 경우에도 동일한 lifetime rule이 적용됩니다. 더 보기 해시 기반 Set, 순서설정, 및 독점 변이.
