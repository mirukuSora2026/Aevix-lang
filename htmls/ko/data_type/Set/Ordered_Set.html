1입니다. 주문한 회원

OrderedSet<T>는 해시 기반 Set 대신 명시적으로 선택하는 정렬 컬렉션입니다. 비교상 동등한 각 원소 집합의 대표 하나를 소유하며 오름차순으로 제공합니다. 최솟값·최댓값 연산과 범위 제한 순회를 지원합니다. 균형 트리 계약에는 해시 정책·버킷 용량이 없습니다. 빈 컬렉션 생성에는 할당이 필요 없고 노드 추가는 실패할 수 있습니다.

설계 초안. 함수 이름, 콜백, 반복자, 특성 및 오류 캐리어는 제안된 Aevix 계약을 정의합니다. 매개 변수 사용 T value 가치에 의하여, &T value 공유 대여, 그리고 &mut T value 단독 대여. 패스 소유자를 호출합니다 x, &x, 또는 &mut x; 복용 &mut owner 에는 mut 바인딩. 기존 참조 및 빌린된 보기는 직접 전달 됩니다. 콜백 별칭, 오류 레코드 및 반환 참조 수명 표기는 설계 설명으로 남아 있습니다. mut를 선언하지 않는 한 바인딩은 변경할 수 없으며 unit는 값 형식입니다. 어떤 구현 또는 장치 지원 청구는이 카탈로그에서 다음과 같습니다.

2입니다. 안정적인 순서

요소 관계는 완전하고 전이되어야하며 멤버가 저장되는 동안 안정적으로 유지되어야합니다. 비교자 동등성은 선택된 평등 계약에 동의해야 합니다. NaN-베어링 숫자 키는 명시적인 총 순서 래퍼 또는 정책이 필요합니다. 쿼리 순서는 저장된 순서에 동의해야 합니다. 비교자의 변경 외부 상태는 논리 오류입니다; 안전한 컬렉션이 유효하지 않은 참조를 제조하거나 자유롭게 저장소에 액세스하게 해서는 안 됩니다.

3입니다. 회원 및 대여

멤버들은 변함없이 대여만 받습니다. 순서 관련 데이터를 변경하려면 멤버를 제거하거나 수정하기 전에 멤버를 제거한 다음 가능한 노드 할당 실패를 처리하는 동안 다시 삽입합니다. insert는 기존 동등한 담당자를 유지합니다. 이터레이터는 세트 빌리기를 유지하며, 밸런싱, 제거, 삽입 및 파괴는 다른 안전한 별칭을 통해 라이브 참조를 무효화할 수 없습니다.

4입니다. 실패 경계

InputError는 중복 거부 또는 사전 전달 노드 할당이 실패할 때 사용되지 않는 수신 멤버를 반환합니다. 세트는 문서화 된 사전 비행 실패에 대해 변경되지 않습니다. CollectionError에는 checked 크기, 할당 및 복제 실패가 포함됩니다. 사용자 콜백 및 최종 처리기는 롤백 트랜잭션이 아닙니다. 콜백 풀림은 초기화된 메모리를 보존하는 반면 이전 제거 및 외부 효과는 유지될 수 있습니다. 안정적인 노드 주소, 할당자 레이아웃 또는 영점 보장은 제공되지 않습니다.

6입니다. 정렬된 범위 및 예제

범위가 반쯤 열려 있습니다. 더 낮은 것이 포함되고, 위쪽은 제외됩니다. 동일한 경계는 값을 생성하지 않습니다. 반전된 경계는 항복하기 전에 return RangeError입니다. 경계는 횡단을 찾고 더 이상 건설할 필요가 없습니다; 산출된 멤버 참조는 세트에 묶여 있습니다. 범위는 로그 설정 후 k 개의 일치하는 요소를 방문합니다. 

OrderedSet<i32> empty = OrderedSet.new(i32);
usize count = OrderedSet.len(&empty);
Optional<&i32> least = OrderedSet.first(&empty);

7입니다. 대수학 및 관련 유형

현재 대수학 카탈로그 정렬된 Merge 반복자를 정렬된 집합에 대해 정의합니다. 그들은 두 세트를 모두 빌리고, 출력 할당이 필요하지 않으며, 증가하는 순서를 유지합니다. 소유 된 결과는 명시 적 복사 또는 복제 및 오류 저장 구조가 필요합니다. 로그 키 검색에는 여전히 비교 비용이 포함되어 있으며 제거된 멤버와 최종 사용자에게는 파괴가 선형입니다. 더 보기 Set, 명령된맵, 및 Slice.
