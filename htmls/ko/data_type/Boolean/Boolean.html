1입니다. 개요

설계 초안. 이들은 제안된 Aevix API이며, 컴파일러나 표준 라이브러리가 이를 구현한다고 주장하는 것은 아니다. 매개 변수 모드가 선택됩니다. T value, &T value, 및 &mut T value. 타입 팩·호출 가능 타입·반환 참조의 명시적 수명 표기·오류 enum은 표시된 곳에서 설명용으로 남습니다. 모든 연산은 네임스페이스 함수를 사용하며 값 메서드 별칭은 없습니다.

bool 이것은 정확히 false와 true를 나타냅니다. 그것은 조건과 예언의 유형입니다. 정수, 문자열, 포인터 및 Optional 값은 암시적으로 조건이 되지 않습니다. 존재 확인 사용 Optional.is_some(value)정수 진리 변환은 그 정책을 명시적으로 이름짓는다.

2입니다. 선언과 리터럴

선언은 형식을 먼저 놓고 기본적으로 변경할 수 없습니다.Declarations put the type first and are immutable by default. 토큰 true 및 false 기본 정수 별칭과 독립적으로 bool를 입력합니다. bool 스칼라는 Copy입니다. 복사하면 가변 상태가 할당되거나 공유되지 않습니다. 

bool ready = true;
bool blocked = false;
bool allowed = Boolean.and(ready, Boolean.not(blocked));

3입니다. 열망하는 외침 및 단락

일반 함수 인수는 함수 호출 전에 평가됩니다. Boolean.and(expensive_a(), expensive_b()) 따라서 두 호출을 모두 평가합니다. 선택된 언어 운영자 && 및 || bool 피연산자를 가져 와서 필요한 경우에만 올바른 피연산자를 평가하십시오. 트리너리 condition ? a : b 마찬가지로 선택된 브랜치만 평가합니다. 더 보기 연산자와 표현식.

Boolean.then 호출을 수락하고 조건적으로 호출합니다.Accept a callable and invokes it conditionally. Boolean.select 이미 만들어진 두 개의 값입니다. 어느 이름도 하드웨어 브랜치, 상수 시간 실행, 또는 보안 타이밍 보장을 의미하지 않는다.

4입니다. 표현 및 유효한 값

시맨틱 도메인은 두 가지 값을 가집니다. 이 초안은 대상 ABI 정의에 따라 저장된 독립 실행형 bool에 대해 하나의 주소 지정 가능한 byte를 제안합니다. 벡터, 텐서 마스크, 포장된 레코드 또는 외국 불리언에 대해 동일한 레이아웃을 약속하지 않습니다. 임의 byte 패턴은 안전 코드에서 유효한 bool 값으로 재해석할 수 없습니다.

packed-bit 컨테이너는 proxy 및 concurrency 비용을 가진 별도로 지정된 표현이 될 것입니다. Vector<bool> 고유한 포장 유형을 도입하지 않는 한 일반 인접 요소 모델을 따릅니다.

5입니다. 숫자 및 텍스트 변환

현재 0.2 프로파일에는 암시적 bool-to-integer 또는 정수-to-bool 변환이 없습니다. Boolean.from_integer 인코딩된 논리 값을 검증합니다. Boolean.from_nonzero 다른 정책을 요구한다. 이 구별은 2와 같은 손상된 플래그 값이 자동으로 엄격한 디코딩을 통과하는 것을 방지합니다.

계획된 0.3 추가 기능: 스칼라 정수형에 대한 명시적 반환 0에 false를 적용하고 1에 true를 적용할 수 있습니다. 이 좁은 규칙은 초기화, 인수, 산술 또는 bool 전용 조건을 변경하지 않습니다. 동일한 계획 일정 Boolean.to_integer<T> 다른 곳에서 명시적 변환을 위해; 이 카탈로그의 나머지는 설계 제안서로 남아 있습니다.

포맷은 소문자 ASCII를 사용하고 로케일을 사용하지 않습니다. 파싱은 공백을 트리밍하지 않습니다. 발신자 제어 트리밍은 입력 형식이 허용하는 경우 구문 분석하기 전에 발생해야 합니다. UTF-8 텍스트 및 원시 byte 스토리지는 별개의 상태로 유지됩니다.

6입니다. 함수 참조

T value 는 값을 전달합니다. Copy 타입은 복사하며 소유 non-Copy 값은 깊은 clone 없이 이동합니다. &T value 는 공유 읽기 대여이고 &mut T value 는 배타적 변경 대여입니다. 호출 시 각각 x, &x, 또는 &mut x 를 사용합니다. 이미 대여한 참조·뷰 값은 직접 전달하며 &를 하나 더 붙이면 타입이 바뀝니다. *ref 는 참조 대상을 읽고 씁니다. 일반적인 &mut x 에는 mut 소유자가 필요합니다. mut T value 만으로는 값 매개변수가 함수 안에서 변경 가능해질 뿐 호출자의 값을 변경하지 않습니다. 겹치는 활성 대여는 마지막 사용까지 검사합니다. 서로 겹치지 않는 영역은 안전하게 나눌 수 있으며 대여는 원본보다 오래 살 수 없습니다. 동기화된 내부 변경은 해당 타입의 계약을 따릅니다. Fn(A) -> B 는 호출 가능한 값을 설명하며 반환 참조의 수명 관계는 본문으로 문서화합니다.

Boolean.or(bool left, bool right)bool두 인자는 호출 전에 평가됩니다; 적어도 하나가 참일 때 true.O(1)
Boolean.xor(bool left, bool right)bool두 주장이 다를 때의 진실.O(1)
Boolean.equal(bool left, bool right)bool두 가지 논리적 가치의 평등.O(1)
Boolean.compare(bool left, bool right)Orderingfalse precedes true : 거짓이 사실보다 앞서다. 이것은 강제적 인 것이 아닙니다.O(1)
Boolean.select(bool condition, T yes, T no)T열심히 구성된 대안; 선택한 값을 이동하고 선택되지 않은 값을 한 번 파괴합니다.O(1) 선택 + 하락 비용
Boolean.then(bool condition, Fn() -> T make)Optional<T>호출은 true일 때만 한 번 호출하며, 그렇지 않으면 None을 반환합니다. 관찰 가능한 콜백 평가가 없습니다.O(1) + 옵션 콜백
Boolean.then_some(bool condition, T value)Optional<T>값은 열망적입니다; false는 그것을 파괴하고 None을 반환합니다.O(1) + 가능한 드롭
Boolean.ok_or(bool condition, E error)Result<unit, E>True는 Ok(Unit.value())를 반환합니다. false는 오류를 이동시킵니다. 사용하지 않은 오류가 발생합니다.O(1) + 가능한 드롭
Boolean.ok_or_else(bool condition, Fn() -> E make_error)Result<unit, E>False일 때만 오류를 생성합니다.O(1) + 옵션 콜백

Boolean.any(Slice<bool> values)bool빈 조각에 대해 거짓; 순서대로 읽고 첫 번째 true에서 멈 춥니 다.O(n) 최악의 경우
Boolean.count_true(Slice<bool> values)usizetrue 요소를 계산합니다. 결과는 유효한 슬라이스 길이를 초과할 수 없습니다.O(n)

7입니다. 오류 및 버퍼 원자성

BooleanError InvalidRepresentation 및 InvalidText를 포함하는 제안된 오류 열거형입니다. BufferError 필수 및 사용 가능한 byte 카운트를 포함합니다. 용량 유효성 검사에 실패하면 포맷 버퍼가 변경되지 않습니다. 부분적으로 인코딩된 논리적 토큰이 성공으로 노출되지 않습니다.

순수한 스칼라 연산은 오버플로우할 수 없습니다. 콜백 실패는 콜백 계약에 의해 제어됩니다. Boolean 도우미가 할당 실패를 false로 바꿉니다.

8입니다. 병렬 및 장치 사용

불변의 bool 값을 독립적인 작업으로 복사할 수 있습니다. Concurrent는 동일한 bool에 여전히 독점적 인 대여, 잠금 또는 지원을 필요로합니다. Atomic<bool> 가동. Copy는 동기화되지 않은 공유 쓰기를 안전하게 만들지 않습니다.

CPU bool는 자동으로 SIMD 레인 마스크 또는 GPU 술어 레지스터가 아닙니다. 이러한 표현으로의 변환은 해당 API에서 명시적입니다. bool 값을 이동하면 장치 전송 시맨틱이 없습니다.

9입니다. 외부 인터페이스

C _Bool, C++ bool, Python bool 및 외국 정수 플래그는 바인딩 규칙이 다릅니다. 바인딩은 외국 ABI를 사용하여 값을 검증하고 변환합니다; 원시 주소는 표현 계약을 설정하지 않습니다. Python 개체 참조 관리는 Boolean 스칼라 저장소가 아닌 Python 경계에 속합니다.

참고: byte 스토리지 규칙 및 원자 능력 변색된 국기를 노출하기 전에.

10입니다. 예제 및 경계 사례 

Result<bool, BooleanError> valid = Boolean.from_integer(1);
Result<bool, BooleanError> invalid = Boolean.from_integer(2);
Result<bool, BooleanError> token = Boolean.parse("true");
bool nonzero = Boolean.from_nonzero(-3);
i32 encoded = Boolean.to_integer<i32>(ready);

이러한 예는 엄격한 유효성 검증과 의도적인 0이 아닌 변환을 구별합니다. 잘못된 입력은 오류 값을 반환합니다; 이미 평가된 인수는 never 소급적으로 게으르게 만들어졌습니다.
