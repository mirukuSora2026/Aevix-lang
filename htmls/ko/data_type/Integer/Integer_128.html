2입니다. 문자 및 상수Lite and constants

접미사 사용 i128 리터럴의 형식을 수정하거나 일치하는 선언 컨텍스트를 제공합니다. 십진법, 0x 16 진수, 0b 바이너리, 그리고 0o 8진법 철자가 지원됩니다. 접미사는 리터럴의 일부입니다; 다른 선언된 타입으로의 변환을 요구하지 않습니다.

const i128 MINIMUM = -170141183460469231731687303715884105728i128;
i128 large = 1267650600228229401496703205376i128;
i128 contextual = 1267650600228229401496703205376;

기호와 리터럴 크기는 함께 checked이므로 최소 서명 리터럴이 유효합니다. 이미 입력된 최소값은 별도의 산술 연산이며 오버플로에서 안전하게 멈춥니다. 가장 높은 비트 세트의 16진수 값은 자동으로 음수가 되지 않습니다.

컴파일-시간 산술은 런타임 산술과 동일한 입력된 범위를 사용합니다. out-of-range 리터럴과 failing 상수 표현식은 컴파일 오류입니다. 이것은 고정폭 산술(fixed-width arithmetic)이며, 임의의 정밀도의 런타임 정수가 아니다.

3입니다. 작업자 및 고장 경계

상기 실시예들은 The implemented operators +, -, *, /, %, 단항 +, 단항 -, 비교, &, |, ^, ~, <<, 및 >>. 산술은 일치하는 피연산자 유형이 필요합니다. 또한 가변 바인딩은 기존 컴파운드 할당 및 increment/decrement 규칙을 지원합니다.

일반 산술은 오버플로우, 부호 없는 언더플로우 또는 0으로 나누기 전에 안전하게 중지됩니다. 그것은 포장하지 않으며 return를 Result하지 않습니다. 같은 수표가 적용됩니다. -O0, -O2, AOT 및 JIT입니다.

디비전은 0으로 자르고, 나머지가 0이 아닌 것은 배당의 기호를 갖습니다. 둘 다 최소 나누기 -1i128 최소 남은 수량 -1i128 안전하게 멈추세요. 부호 있는 오른쪽 교대는 기호 비트를 확장합니다.

shift count가 있어야 합니다. 0..128따라서 가장 큰 유효 값은 127입니다. 유효한 왼쪽 쉬프트는 128-bit 표현 이상으로 비트를 버린다. 카운트 유효성 검사는 checked 산술 오버플로와 별개입니다.

i128 value = -1267650600228229401496703205376i128;
i128 quotient = value / 3i128;
i128 remainder = value % 3i128;
bool identity = quotient * 3i128 + remainder == value;

4입니다. 명시적 숫자 변환

이미 입력된 숫자는 암시적으로 변환되지 않습니다. 대상 유형을 명시적 일반 인수로 사용합니다. 성공적인 정수 변환은 수학적 값을 보존합니다; 대상의 범위 밖에 있는 값이 반환됩니다. IntegerError.OutOfRange.

Result<i128, IntegerError> widened = Integer.convert<i128>(18446744073709551615u64);
Result<u64, IntegerError> negative = Integer.convert<u64>(-1i128);
기능의미
Integer.convert<D>(value)signed 및 unsigned 128-bit 대상을 포함한 정수 대 정수 변환을 확인했습니다.
Float.convert<F>(value)플로팅 타입으로의 명시적인 변환; 유한 라운딩은 허용됩니다.
Float.convert_exact<F>(value)반환 FloatError.NonExact 수학적 가치가 정확하게 표현 될 수없는 경우.
Float.to_integer_exact<D>(value)대상 범위 내에 유한한 일체형 입력이 필요합니다.

부동 함수 return Result<D, FloatError> 구별하여 OutOfRange, NonFinite, 및 NonExact. 128-bit 정수는 부동형의 크기 범위에 적합하고 여전히 정밀도를 잃을 수 있습니다. Result를 처리하거나 일치하는 오류 유형을 다음과 같이 전파합니다. ?.

5입니다. Range 반복 및 카운트

Range<i128> 및 Range<u128> 최소 또는 최대에 인접한 짧은 범위를 포함하여 일반 반복을 지원합니다. 커서를 감싸는 대신 유형 경계를 지나갑니다.

Range<i128> edge = Range.closed(-170141183460469231731687303715884105728i128, -170141183460469231731687303715884105726i128);
mut usize count = 0;
for (i128 value in edge) count++;
Result<usize, RangeError> length = Range.len(&edge);

이 예제는 세 가지 값을 방문합니다. Range.len checked를 반환합니다. usize count입니다. 값의 수학적 수를 초과하는 경우 usize# IT 복귀 RangeError.CountOverflow. 부호 없는 모든 128-bit 값에 걸쳐 닫힌 범위에 2 포함128 값, 따라서 길이는 64-bit count로 반환될 수 없습니다.

6입니다. 스토리지, 집계 및 ABI

128-bit 정수는 스칼라 값, 함수 인수 및 return 값, 구조체 필드, 일반 인수, 고정 배열 요소 및 Result 페이로드로 작동합니다. 스칼라 복사본은 할당되지 않습니다. 배열과 다른 컨테이너를 소유하는 것은 자신의 움직임을 유지하고 규칙을 빌려.

현재 백엔드는 이러한 값을 LLVM로 저장합니다. i128. 휴대용 런타임 헬퍼는 checked 산술, 변환 및 넓은 범위 수에 대 한 자신의 개인 C 경계를 통해 두 개의 64-bit 단어를 전달 합니다. 따라서 외부 128-bit 컴파일러 도우미 ABI가 필요하지 않습니다. 모든 작업이 하나의 CPU 명령임을 보장하지는 않습니다.

유형 C FFI 모수와 return 가치를 지시하십시오 i128 또는 u128 0.2에서 거부됩니다. 외국 ABI 및 집계 레이아웃 계약은 해당 시그니처을 지원 하기 전에 설계 해야 합니다.

7입니다. 검증 범위

0.2 테스트는 최소 리터럴 및 최대 리터럴, 컴파일 시간 산술, checked 런타임 작업, 비트 시프트, 숫자 변환, 범위 경계 및 길이 오류, struct/array 레이아웃, 일반 통화 및 Result 페이로드를 연습합니다. AOT 및 ORC JIT는 다음과 같은 의미론적 사례를 실행합니다. -O0 및 -O2.

또한 휴대용 런타임에는 64-bit 하위 도메인에 대한 결정적 경계 테스트 및 비교가 있습니다. 이것들은 정확성 검사입니다. 이 페이지에서 C++, Rust 또는 다른 언어와의 처리량 비교가 이루어지지 않습니다.
