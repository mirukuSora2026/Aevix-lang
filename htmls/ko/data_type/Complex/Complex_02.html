수입 및 건설

이 페이지는 구현된 0.2 범위를 나열합니다. 더 넓은 설계 카탈로그에는 향후 API도 포함됩니다. Complex 값은 일반적인 제네릭 라이브러리 구조체이며 import한 경우에만 불러옵니다.

import complex { Complex, complex, ComplexError };

i32 main() {
    complex value = complex.new(3.0, 4.0);
    Complex<f32> single = Complex<f32>.new(3.0f32, 4.0f32);
    return complex.magnitude(value) == 5.0 ? 42 : 1;
}

Complex<T = f64> #공공 T real 및 T imag 필드. 투명한 별칭 complex 는 다음 표기와 같습니다: Complex<f64>. 전체 모듈로 import complex;, 사용 complex.Complex<f64>. 모호한 C-폭 별칭이나 가상의 접미사가 할당되지 않습니다.

숫자적 행동

각 구성 요소에는 자체 형식과 반올림이 있습니다. 일반적인 산술은 그 구성 요소를 사용합니다. 안정적인 크기 및 분할은 이미 둥근 입력 구성 요소를 f64로 홍보하고 각 최종 결과를 T로 되돌려줍니다. 추가 입력 정밀도를 생성하지 않습니다.

Magnitude는 확장된 표준 수치 구현을 사용하여 real2 + imag2를 명시적으로 형성하는 불필요한 오버플로를 피합니다. 무한대는 NaN 성분을 크기로 지배합니다; 그렇지 않으면 NaN 성분은 NaN를 일으킵니다. 0 등급은 양수 0입니다.

유한 분할은 각 출력 성분을 형성하기 전에 제품 만티사와 이진 지수를 분리합니다. 이것은 제품에서 불필요한 오버플로를 방지하고 거대한 실제 구성 요소 옆에 작은 가상의 구성 요소를 보존합니다. 무제한 입력은 플랫폼 표준 복잡한 복구 규칙을 사용합니다. 올바르게 반올림 된 결과, NaN 페이로드 보존 또는 모든 플랫폼 수학 라이브러리에서 동일한 마지막 비트가 약속됩니다.

NaN과 무한대는 수치 값이며 자동으로 Result 오류가 되지는 않습니다. 이 구현 범위에서 Complex 값에는 암시적 순서나 새로운 연산자 오버로딩이 없습니다.

오류 및 소유권

부호 있는 0을 포함하여 두 성분이 모두 0인 분모가 반환됩니다. ComplexError.ZeroDivisor. Result를 확인하거나 그것을 전파 ?. ComplexError Copy를 구현합니다.

import complex { complex, ComplexError };

Result<complex, ComplexError> quotient() {
    complex a = complex.new(3.0, 4.0);
    complex b = complex.new(1.0, -2.0);
    complex result = complex.div(a, b)?;
    return Result.ok(result);
}

Complex 값은 소유한 힙 할당을 포함하지 않습니다. 값을 복사하면 두 성분을 복사합니다. 런타임 수치 보조 함수는 스칼라 인수와 호출자가 제공한 출력 저장소를 사용하며, 메모리를 할당하거나 예외를 던지지 않습니다. 사용자 모듈에서는 비공개 구현 보조 함수에 접근할 수 없습니다.

형식 및 범위

AOT 및 JIT는 동일한 checked 언어 파이프라인을 사용합니다. 런타임 지원은 대상 플랫폼과 일치해야 합니다. 초월적인 복잡한 기능, 극 변환, 복잡한 SIMD 및 GPU 실행은 향후 작업으로 남아 있습니다.
