1입니다. 통합 변형은 한 부모 유형에 속합니다.

열거형 선언은 하나의 명명된 형식을 도입합니다. 빈 변형은 데이터 없는 경우를 나타내며 페이로드 변형은 명명된 형식 필드를 전달합니다. 두 폼의 값에는 부모 열거형 형식이 있습니다. Aevix는 빈 열거형과 데이터 열거형을 별도의 선언 메커니즘으로 분리하지 않습니다.

일반 열거형 값은 기본값으로 이동합니다. 가시성, 페이로드 초기화, Copy 자격 및 인터페이스 구현은 전체 선언에 대해 checked입니다. 이러한 요구 사항은 구현 된 컴파일러의 결과가 아닌 언어 디자인 계약입니다.

2입니다. 빈 및 이름있는 페이로드 변형 선언

public enum Event {
    Quit;
    Move {
        public i32 x;
        public i32 y;
    };
    Message {
        public string text;
    };
};

quit가 비어있습니다. 이동은 두 개의 i32 필드를 전달합니다. 메시지에는 string 소유가 포함되어 있습니다. 필드는 일반적인 type-first 선언 형식을 사용합니다. 각 빈 변형은 세미콜론으로 끝나고, 각 페이로드 변형은 };로 닫히며, 전체 열거형도 };로 닫힙니다.

이 선언은 기본적으로 변형 이름을 공개합니다. 페이로드 필드는 여기에서 명시적으로 공개되므로 Event 외부의 코드가 다음 예제에서 초기화하고 바인딩할 수 있습니다. public이 없는 필드는 private입니다.

3입니다. 필요한 모든 페이로드 필드 초기화

Event make_quit() {
    Event event = Event.Quit;
    return event;
}

Event make_move(i32 initial_x, i32 initial_y) {
    Event event = Event.Move { x = initial_x, y = initial_y };
    return event;
}

Event make_message(string initial_text) {
    return Event.Message { text = initial_text };
}

Event.Quit는 빈 변형 값입니다. Event.Move { ... } 및 Event.Message { ... }는 named-payload 이니셜라이저입니다. 필요한 모든 필드가 있어야 하며 이니셜라이저 위치에서 액세스할 수 있어야 합니다. 기본 페이로드 값은 가정되지 않습니다.

initial_text 를 Message 로 옮기면 소유권이 이전됩니다. 이 구문에서만 깊은 string 복제 또는 숨겨진 할당이 요청되지 않습니다. 반환되는 각 값에는 여전히 Event 유형이 있습니다. Event.Move는 별도로 선언된 유형이 아닙니다.

Event.Message와 같은 페이로드 변형 이름만으로는 완전히 구성된 값이 아닙니다. 태그 전용 케이스 라벨은 다음과 같이 문서화된 다른 패턴 작업입니다. Enum Switch.

4입니다. 다양한 액세스 및 페이로드 액세스는 별도입니다.

변형 이름인기 있는개인 변형;구성 또는 일치에 대한 변형 이름을 지정하는 컨트롤입니다.

개인 페이로드 필드가 있는 공용 변형은 해당 유형 외부의 태그 전용 케이스에서 이름을 지정할 수 있습니다. 그 변형을 명명하는 것은 액세스 할 수없는 필드의 건설 또는 그 내용을 바인딩 권한을 부여하지 않습니다. 개인 변형은 외부 코드에 의해 명시적으로 명명될 수 없습니다.

가시성 never는 열거형 값 또는 빌린 필드의 수명을 연장합니다. 로컬 바인딩은 여전히 어휘적 범위에 속하며, 중첩된 로컬은 보이는 외부 이름을 숨길 수 없습니다.

5입니다. 유형 함수를 사용하여 개인 페이로드 구성

public enum Credential {
    Token {
        string secret;
    };
    private Internal;

    private Credential from_secret(string initial_secret) {
        return Credential.Token { secret = initial_secret };
    }

    public Credential issue(string initial_secret) {
        return Credential.from_secret(initial_secret);
    }
};

Credential issue_credential(string initial_secret) {
    return Credential.issue(initial_secret);
}

from_secret 은 개인 리시버리스 타입 함수입니다. issue 는 그것을 사용하는 공개 타입 함수입니다. 둘 다 Credential 내부에 있으며 private secret 필드를 초기화할 수 있습니다. 외부 코드는 Credential.issue를 통해 자격 증명을 구성하지만 필드에는 액세스 할 수 없습니다.

팩토리 이름은 일반적인 함수 이름입니다. 생성자 전용 키워드, 정적 저장소 수정자 또는 암시적 페이로드 기본값이 도입되지 않았습니다. persist는 저장소 기간을 제어합니다.

6입니다. 열거형 이동은 활성 페이로드 이동

Event relay_event(Event source) {
    Event transferred = source;
    return transferred;
}

Copy를 구현하지 않는 열거는 일반 값 할당, by-value 매개 변수 및 반환을 통해 이동합니다. 활성 페이로드는 전송된 값을 따릅니다. 불변 바인딩은 이동할 수 있다; 불변성은 소유권 이전보다는 일반적인 변경를 금지한다.

원본 바인딩은 이동 후 사용할 수 없습니다. 비활성 변형은 복제하거나 정리할 라이브 페이로드가 없습니다. 공유 읽기 대여 또는 열거형 읽기 스위치는 소유자를 전송하지 않고 활성 값을 관찰 할 수 있습니다.

Normal scope exits는 정확히 한 번 역 초기화 순서로 여전히 로컬로 소유한 리소스를 정리합니다. 이동한 열거형을 반환하면 발신자에게 소유자가 되며 로컬로도 파괴되어서는 안 됩니다. 메모리 레이아웃과 사용자 지정 enum 정리 후크는 열려 있습니다.

7. 모든 가능한 변형을 검증하는 Copy 구현

enum Axis implements Copy {
    X;
    Y;
    Offset {
        public i32 amount;
    };
};

Axis copy_axis(Axis source) {
    Axis duplicate = source;
    return duplicate;
}

Copy는 내장형 checked 기능입니다. 모든 변형의 모든 페이로드 필드는 개인 변형 및 개인 필드를 포함한 Copy 요구 사항을 충족해야합니다. 빈 변형은 페이로드 필드를 제공하지 않습니다. 이 검사는 현재 활성화된 변형뿐만 아니라 전체 열거형 유형에 적용됩니다.

허용되지 않는 예제. 확정된 규칙을 의도적으로 위반하므로 유효한 Aevix 코드가 아닙니다.

enum InvalidEvent implements Copy {
    Quit;
    private Message {
        string text;
    };
};

string 소유가 Copy가 아니므로 InvalidEvent는 외부 코드가 메시지의 이름을 지정할 수 없는 경우에도 Copy를 구현할 수 없습니다. 컴파일러는 런타임에 어떤 변형이 저장되는지에 대한 이 결정을 기초로 해서는 안됩니다.

참고: Copy 공유된 능력의 계약 Copy는 깊은 클론, 사용자 정의 클론 방법, 안정적인 ABI 또는 운영자 과부하를 약속하지 않습니다.

8입니다. 열거형 재사용 유형 함수 및 자체 수신기

enum Signal {
    Stop;
    Value {
        public i32 amount;
    };

    public Signal value(i32 initial_amount) {
        return Signal.Value { amount = initial_amount };
    }

    public Signal into_signal(Signal self) {
        return self;
    }
};

Signal relay_signal(i32 amount) {
    Signal signal = Signal.value(amount);
    return signal.into_signal();
}

value 는 self 매개 변수가 없으므로 type 에 호출됩니다. into_signal 에는 by-value self 매개 변수가 있으므로 호출은 비 Copy 신호의 소유권을받습니다. 그런 다음 반환된 소유자가 호출자로 이동합니다.

공유 메서드 형태는 값 수신기 T self, 읽기 수신기 &T self 및 수정 수신기 &mut T self입니다. Public/private 액세스 및 명시적 수신기 기능은 구조체와 동일한 규칙을 따릅니다. 적절한 활성 페이로드는 모든 변형이 동일한 필드를 갖는 척하기보다는 스위치 패턴을 통해 액세스됩니다.

비-void 메서드는 일반 완성에 대한 값을 명시적으로 return 합니다. enum 메소드 스위치의 모든 case/default는 여전히 명시 적으로 끝납니다. break;허용된 return 이후를 포함하여, enclosing-loop continue, divergence 또는 Result ? 필요한 터미널 break는 단순히 이전 종료로 인해 연결할 수 없기 때문에 오류나 경고를 생성하지 않습니다. 성공 ? break를 향해 계속; Err는 함수를 종료합니다. 일반 출구는 정확히 한 번만 떠나는 지역만 정리합니다. 일반적인 도달할 수 없는 코드 정책 및 안전 정지 정리는 별도의 열린 주제입니다. 더 보기 case 종료.

9입니다. 인터페이스 구현은 전체 열거형을 포함합니다.

일반적인 구현 인터페이스 선언은 전체 열거형 형식에 속합니다. 인터페이스에서 Self는 부모 열거형을 의미합니다. 개별 변형을 의미하지 않으며, 각 변형은 독립적 인 구현자가되지 않습니다.

열거형은 선택한 인터페이스 디스패치, 기본 메서드 및 재정의 계약을 재사용합니다. 메서드는 활성 변형에서 스위치를 통해 동작을 결정할 수 있지만 시그니처은 여전히 하나의 enum 구현을 충족합니다. 변형 가시성은이 의무에서 개인 변형을 제거하지 않습니다.

참고: 인터페이스 표준 선언 및 방법 요구 사항, 그리고 일반 유형 형식 매개 변수 제약 조건. Copy와 같은 내장 기능은 전체 열거형에도 적용되며 추가 컴파일러 유효성 검사가 제공됩니다.

interface Leveled {
    public i32 get_level(&Self self);
};

enum LevelState implements Leveled {
    Beginner;
    Experienced;

    public i32 get_level(&LevelState self) {
        mut i32 level = 0;
        switch (*self) {
            case LevelState.Beginner:
                level = 1;
                break;
            case LevelState.Experienced:
                level = 2;
                break;
        }
        return level;
    }
};

Leveled의 Self가 LevelState에 매핑되므로 구현이 &LevelState self를 수신합니다. 필요한 메서드는 일반 공개 선언입니다. 재정의는 상속된 기본 구현을 대체하기 위해 예약되어 있습니다. 스위치는 읽기 대여을 위해 *self를 통해 열거형 참조 장소를 명시적으로 선택합니다. 그것은 공유 참조에서 열거를 이동하지 않습니다.

10입니다. 거부된 초기화 및 가시성 예제

허용되지 않는 예제. 확정된 규칙을 의도적으로 위반하므로 유효한 Aevix 코드가 아닙니다.

Event incomplete_move(i32 initial_x) {
    return Event.Move { x = initial_x };
}

이동은 x와 y 모두를 필요로 합니다. 누락된 필드에는 암시적 기본값이 없습니다.

허용되지 않는 예제. 확정된 규칙을 의도적으로 위반하므로 유효한 Aevix 코드가 아닙니다.

Credential inaccessible_payload(string initial_secret) {
    return Credential.Token { secret = initial_secret };
}

이 함수는 Credential 외부에 있으므로 private secret을 초기화할 수 없습니다. 공공 팩토리을 이용하십시오. 공개 토큰 변형의 태그 전용 일치는 비밀을 밝히지 않고 여전히 허용됩니다.

허용되지 않는 예제. 확정된 규칙을 의도적으로 위반하므로 유효한 Aevix 코드가 아닙니다.

Event invalid_payload_value() {
    return Event.Message;
}

메시지에 페이로드 이니셜라이저가 필요합니다. 태그 전용 표기은 생성자 값이 아닌 케이스 레이블로 허용됩니다. 이러한 예제는 실제 컴파일러 진단이 아닌 의도된 거부를 정의합니다.

11입니다. 열린 열거된 결정

  • 수치 판별, 명시적 변형 번호, 메모리 레이아웃, 태그 크기, 틈새 최적화 및 안정적인 외국 ABI.
  • 자동 equality/ordering, 오퍼레이터 파생, 자동 클론 생성 및 사용자 정의 클론 컨벤션.
  • 사용자 정의 열거형 정리 및 부분 페이로드 이동과의 상호 작용.
  • 전체 파서 문법, 초기화 기본값, 오버로드 해상도 및 추가 생성자 속기.
  • enum 스위치 외부의 일반 이동 식과 Copy 열거형에 대한 명시적 스위치(move ...)의 특수 처리.
  • 확장 패턴 기능, 참조 소스 모드 추론 및 임시 선택기 수명 세부 정보; Enum Switch를 참조하십시오.
