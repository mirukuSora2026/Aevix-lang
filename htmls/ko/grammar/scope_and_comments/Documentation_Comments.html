1입니다. 일반 블록 주석의 메타데이터

Aevix는 일반을 사용 /* ... */ 문서 메타데이터에 대한 코멘트. 분리 된 /** ... */ 형태는 요구되지 않는다. comment-content 라인의 시작에서 인식된 태그들은 다음의 선언을 직접적으로 기술한다; comment는 여전히 실행가능한 문을 도입하지 않는다.

설계 문서. 확정된 언어 규칙은 직접 설명하고, 미정 정책과 권고안은 따로 표시합니다. 이 예제들이 컴파일러·런타임·진단 시스템의 구현을 뜻하지는 않습니다.

/*
 * Return the supplied integer unchanged.
 * @parameter value The integer to return.
 * @return The same integer value.
 */
i32 identity(i32 value) {
    return value;
}

2입니다. 선 시작과 선택적인 주요한 별

블록 주석 구분 기호를 제거한 후 인식된 태그가 콘텐츠 라인을 시작하여, 선행 공백과 선택적 선행을 허용합니다. *. 별은 프레젠테이션이며, 별도의 문서 주석 토큰이 아닙니다. 일반적인 묘사 선은 산문에 남아 있습니다.

/*
@parameter value The input integer.
@return The input value.
*/
i32 plain_comment_style(i32 value) {
    return value;
}

산문 문장 중간에 삽입된 태그는 새로운 메타데이터 항목이 되지 않습니다. 표시된 두 레이아웃 모두 동일한 일반 주석 구분 기호를 사용합니다. 이 참조는 중첩된 블록 주석, 마크업 언어 또는 주석 종료자에 대한 이스케이프 규칙을 추가하지 않습니다.

3입니다. 선언에 메타데이터 첨부하기

문서 블록을 선언 전에 직접 배치합니다. 첨부 파일은 해당 선언에 대한 것이며, 과거의 진술과 범위 경계를 스캔하여 나중에 이름이나 관련없는 선언을 사용하는 것이 아닙니다. 주석은 어휘적 가시성을 변경하거나 선언을 살아있게 유지하지 않습니다.

선택한 규칙은 직접 첨부를 설정합니다. 여러 블록, 중복 태그 해상도, 교차 파일 추출 및 향후 선언 속성에 대한 배치를 결합하는 것은 열려 있습니다. 이러한 불합리한 조치는 피할 수 없다.

4입니다. 5개의 인식된 태그

태그내용선택된 의미
@parameter name description매개 변수 이름 뒤에 설명 텍스트가 있습니다.지정된 매개 변수를 설명합니다. 여러 매개 변수에 대해 반복합니다.
@return description선언 된 return 계약에 대한 설명.결과를 문서화하십시오; 이것은 return 문이 아닙니다.
@version versionAPI 문서 버전 값입니다.메타데이터, 런타임이나 언어 모드 스위치가 아닙니다.
@deprecated reason/replacement이유 and/or 교체 지침.문서의 폐기를 표시하고 설명하십시오.
@deprecated_at versiondeprecation 표시가 시작된 API 버전입니다.삭제 버전이나 자동 활성화 조건이 아닙니다.

canonical deprecation 태그는 다음과 같습니다. @deprecated. 태그는 첨부된 선언을 기술합니다; 매개변수 유형, return 유형, 대여 권한 또는 ABI는 변경되지 않습니다.

5입니다. 각 매개 변수 설명

각 매개 변수에 대해 @parameter를 반복합니다. 이름은 매개 변수를 식별하고 나머지 텍스트는 역할, 단위, 소유권 기대 또는 유효한 값을 설명합니다. 태그는 다른 변수를 선언하지 않으며 불변 매개 변수를 변경할 수 없습니다.

/*
 * @parameter left The selected value when choose_left is true.
 * @parameter right The selected value otherwise.
 * @parameter choose_left Whether to select left.
 * @return The selected integer.
 */
i32 select_value(i32 left, i32 right, bool choose_left) {
    if (choose_left) {
        return left;
    } else {
        return right;
    }
}

권장되지 않음 : 문서 검사기는 태그 이름을 선언의 매개 변수 이름과 비교할 수 있습니다. 알 수 없는 이름, 중복, 누락된 태그, 경고 심각도, 검사가 컴파일에 영향을 미치는지 여부가 수정되지 않았습니다.

6입니다. 문서 return 동작

@return 함수의 선언된 결과를 설명합니다. never는 누락된 return 문, 암시적 성공 래퍼 또는 return 경로 검사에 대한 예외를 제공합니다. 값 반환 함수는 여전히 명시 적으로 return 자신의 값을 일반 경로에, 별도로 선택한 ? 오류 전파 약칭은 자신의 계약을 유지.

unit 값 유형과 return 위치 void는 여전히 다릅니다. 태그로 void를 저장할 수 없게 하거나 unit 반환 함수에 필요한 명시적 값 return를 제거할 수 없습니다. Result 설명은 성공과 오류 의미를 구분해야 하며 Optional 설명은 부재를 설명해야 합니다. 특정 선언에 return 태그가 필요한지 여부는 공개 유효성 검사 정책입니다.

7입니다. 문서 버전 메타데이터

@version은 첨부된 API 선언에 대한 버전 정보를 기록합니다. 컴파일러 버전을 선택하거나, 대상 명령을 활성화하거나, 과부하를 선택하거나, 가져오기를 게이트하거나, 런타임 제어 흐름을 변경하지 않습니다. 버전 형식, 순서, 비교, 상속 및 패키지 수준 기본값은 열려 있습니다.

아래의 샘플 버전은 예시적인 API 메타데이터입니다. 기존에 릴리스된 Aevix 라이브러리 또는 지원되는 호환성 일정에 대한 주장이 아닙니다.

8입니다. 삭제 및 교체 안내

@deprecated는 선언을 문서에서 더 이상 사용되지 않는 것으로 표시하고 이유 또는 대체 지침을 제공합니다. 선언을 삭제하거나, 통화를 다시 작성하거나, 교체가 모든 소유권 및 오류 계약을 보존한다는 것을 의미하지는 않습니다. 산문의 대체 이름은 새로운 실행 가능한 별칭이 아닌 지침입니다.

권장되지 않음 : 컴파일러 또는 툴링 레이어는 더 이상 사용되지 않는 선언을 사용할 때 경고할 수 있습니다. 경고 동작, 억제, 심각도, 종속성 전반의 집행 및 내부 용도의 처리는 선택되지 않았습니다. 따라서 이 참조는 구현된 컴파일러가 이미 이러한 경고를 발행한다는 주장을 하지 않는다.

9입니다. Deprecation 마크가 시작되었을 때

@deprecated_at는 선언이 deprecation 마크를 전달하기 시작한 API 버전을 기록합니다. 그것은 역사를 기록한다. API가 제거되는 버전이 아니며, 호출자가 해당 버전을 선택할 때만 마커가 활성화된다는 의미는 아닙니다.

/*
 * @parameter value The integer to return.
 * @return The unchanged integer.
 * @version 2.0
 * @deprecated Prefer identity for new callers.
 * @deprecated_at 1.4
 */
i32 legacy_identity(i32 value) {
    return value;
}

여기서 선언의 샘플 메타데이터 버전은 2.0이며 1.4에서 사용 중지 표시가 시작되었습니다. 자동 삭제 또는 버전별 경고 규칙이 적용되지 않습니다. @deprecated_at가 @deprecated 없이 사용된 상호 작용은 열려 있습니다.

never는 형식 오류, 안전하지 않은 대여, 필요한 return 누락 또는 대소문자 구분 break 누락으로 프로그램을 복구합니다. 문서와 실행 가능한 의미론은 분리되어 있다.

11입니다. 관련 선언 및 범위 규칙

Public/private 배치, 어휘 이름 및 리소스 수명은 문서 태그가 아닌 언어 규칙의 적용을 받습니다. 완전한 module/type 구문, 사용자 지정 소멸자 및 주석 기반 컴파일러 동작은 여기에 추가되지 않습니다.
