1입니다. 이름, 리소스 및 문서

이러한 참조는 어떤 로컬 이름이 보이는지, 자신의 범위가 끝날 때 어떤 일이 발생하는지, 일반적인 블록 주석이 선언을 설명하는 방법을 설명합니다. Aevix의 type-first 선언, 불변 기본값, 명시적 차입 및 소유권 규칙을 재사용합니다.

설계 문서. 확정된 언어 규칙은 직접 설명하고, 미정 정책과 권고안은 따로 표시합니다. 이 예제들이 컴파일러·런타임·진단 시스템의 구현을 뜻하지는 않습니다.

3입니다. 한 눈에 보는 규칙 선택

주제규칙
로컬 이름선언 범위와 중첩 범위에서 사용 가능; public/private는 로컬 수정자가 아닙니다.
보이는 변수 redeclaration중복된 렉시컬 섀도잉은 거부됩니다.
일반 청소초기화 된 현재 소유자는 역 초기화 순서로 한 번 해제됩니다.
대여대여은 소유자의 청소 의무를 수행하지 않고 액세스 할 수 있습니다.
문서/* ... */에 있는 줄 선도 태그를 선언에 직접 첨부합니다.
사용 중지 기록@deprecated_at는 제거 또는 활성화가 아닌 표시가 시작된 API 버전을 기록합니다.

4입니다. 로컬 리소스와 문서화된 함수

/*
 * @parameter value The integer to return.
 * @return The unchanged integer.
 */
i32 documented_identity(i32 value) {
    {
        Vector<i32> scratch = Vector.new(i32);
    }
    return value;
}

중첩된 로컬 소유자는 명시적인 return 전에 끝납니다. 그 이름은 코멘트로 내보내지지 않습니다. 이 디자인 예제에서는 public-local 예외 또는 사용자 지정 소멸자 구문을 도입하지 않습니다.

5입니다. 공개된 의사 결정이 표시됨

각 case 와 default 는 독립적인 암시적 스코프를 가지고 있으며, 외부 no-shadowing 규칙을 따르는 동안 다른 브랜치의 이름을 재사용할 수 있다. struct 및 enum 필드 기본값과 access-checked 초기화가 선택됩니다. 0.2는 또한 그림자 제거 규칙을 유지하면서 겹치지 않는 형제 블록에서 이름 재사용을 허용합니다. 사용자 정의 정리 구문, 실패 가능한-cleanup enforcement 및 일반 빌린 장치 종료 대기 대 거부는 열려 있습니다. 모듈 경로 및 가져오기 이제 규칙을 선택했습니다. 일반적인 안전 중단에 대한 청소 보장은 없습니다. 지속적인 초기화 및 정상 종료 persist 정리 전에 추적 된 리소스 사용자를 기다리는 것을 포함하여 규칙을 선택했습니다.

더 이상 사용되지 않는 경고와 자동 문서 파라미터-이름 검사는 권장사항이지, 확립된 컴파일러 동작이 아닙니다.

6입니다. 언어 참조를 계속

표현식연산자와 표현식

값 연산, checked 정수 오류 및 명시적 Result 전파.

실행제어 흐름

조건부, 반복, 전환 사례 및 일반 영역 종료.

선언변수 및 함수

정적 추론, 가변성, 매개 변수 및 명시적 반환.

현재 데이터 형식 참조 각 값과 자원 계약을 제공합니다. 로 돌아 가기 문법 개요 전체 섹션 맵.
