1입니다. 파일은 모듈을 정의한다; imports는 접근을 정의한다

하나의 .avx 소스 파일은 하나의 모듈을 정의합니다. 구성된 소스 루트 아래의 경로는 논리적 전체 모듈 경로를 결정합니다. 가져오기는 선언 전에 파일의 맨 위에 나타나며 가져오기 파일이 액세스할 수 있는 공개 이름을 명시적으로 제어합니다.

이 참조는 선택된 Aevix 디자인을 기록합니다. 그것은 구현 된 컴파일러, 패키지 관리자, 로더, 진단 시스템 또는 파일 시스템 리졸버를 주장 하지 않습니다. 예제에서 보여지는 소스 경로는 가상의 모듈을 기술한다; 이 문서 트리의 파일에 대한 링크는 아니다.

3입니다. 작은 공공 모듈과 선택적 소비자

예 파일 · src/math/vector.avx · 모듈 math.vector

public struct Point {
    public f64 x;
    public f64 y;
};

public f64 dot(&Point left, &Point right) {
    return (*left).x * (*right).x + (*left).y * (*right).y;
}

public const i32 DIMENSIONS = 2;

예 CONSUMER · 선언 앞에 임포트

import math.vector { Point, dot };

f64 horizontal_projection() {
    Point point = Point { x = 3.0, y = 4.0 };
    Point axis = Point { x = 1.0, y = 0.0 };
    return dot(&point, &axis);
}

점과 점은 math.vector에서 공개되며 소비자가 명시적으로 선택합니다. 치수는 해당 소비자에서 선택되지 않은 상태로 유지됩니다.이 가져오기를 통해 짧은 이름이나 math.vector.DIMENSIONS를 사용할 수 없습니다. 자격을 갖춘 철자는 선택이나 개인 정보를 우회하지 않습니다.

4입니다. 선택한 모듈 계약

지역확정된 규칙
파일 매핑src/math/vector.avx는 math.vector가 됩니다; 별도의 모듈 선언이 없습니다.
소스 루트src/ 기본적으로; 구성이 가능하며, 구성 표기이 여전히 열려 있습니다.
경로 표기Full, case-sensitive module paths only; 상대적인 임포트나 별칭이 없음.
접근 권한모듈 수준 유형, 함수 및 상수는 명시적으로 공개되지 않는 한 비공개입니다.
와일드카드 가져오기import math.vector { * }; 모듈의 공개 이름을 가져옵니다.
애매함explicit/wildcard/local 우선 순위 없음; 모호한 짧은 이름 사용은 거부됩니다.
재수출public import names 명시 적으로, 자신의 이름과 원래 선언 ID를 보존.
모듈 사이클하나의 패키지 내에서 허용됨; 값 초기화는 별도의 종속성 문제입니다.
패키지 사이클하나의 작업 공간에 패키지를 포함하여 패키지 간에 거부되었습니다.
접두사 공존math.vector 및 math.vector.ops는 동시에 독립적인 파일일 수 있습니다.

5입니다. 구문, 소유권 및 초기화를 별도로 유지

선언을 가져오는 것은 호출하거나, 값을 복사하거나, 래퍼를 할당하거나, 데이터를 GPU로 전송하지 않습니다. 일반 함수 인수는 여전히 선택한 값을 사용하고 규칙을 빌려옵니다. 가져오기 자체는 Copy 선언을 하거나 쓰기 권한을 부여하지 않습니다.

수입 및 재수출을 통해 엔트리 모듈에서 도달할 수 있는 모듈은 모든 최상위 persist 선언을 사전 엔트리 초기화에 기여합니다. 가져오기 순서는 값 초기화 일정이 아닙니다. 더 보기 지속 저장소 의존성 순서, 런타임 준비 상태 검사 및 정리.

소스 루트 구성 문법, 전체 식별자 문법, 파일 시스템 간접 정보 및 패키지 version/build 메타데이터가 열려 있습니다. 이러한 열린 세부 사항은 개인 액세스, 선택한 가져 오기 제한 또는 전체 경로 충돌 오류를 약화시키지 않습니다.
