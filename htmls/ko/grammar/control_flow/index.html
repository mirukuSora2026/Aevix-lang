1입니다. 브랜치를 선택하거나 구문을 반복

Aevix는 while, for, switch의 statement-form을 사용한다. 괄호와 bool 값이 필요한 경우의 조건. 하나의 실행 가능한 문장은 주변의 중괄호를 생략할 수 있다; 여러 문장은 블록을 필요로 한다. 물리적 줄 바꿈은 얼마나 많은 문장이 브랜치나 루프에 속하는지를 결정하지 않는다.

이 페이지는 허용된 소스 레벨 디자인을 기록합니다. 그들은 구현 된 파서, 최적화, 대여 검사기 또는 런타임을 주장하지 않습니다. 불안정한 정책은 C++, Java 또는 다른 언어에서 유추되지 않고 명시적으로 나열됩니다.

3입니다. 선택한 구문의 간단한 투어

int maximum(int left, int right) {
    if (left > right) return left;
    else return right;
}

int sum_first_ten() {
    Range<int> indices = 0..10;
    mut int total = 0;
    for (int index in indices) total += index;
    return total;
}
구축선택한 양식키 규칙
조건부if (condition) statement;조건은 bool입니다. 표현식 형식이 없는 경우.
조건부 값condition ? first : second선택된 값만 평가됩니다; 두 대안은 같은 타입을 가집니다.
동안while (condition) statement;조건은 각 iteration의 앞에 시험됩니다.
Range를 위한for (int index in range)Range<int> 값 또는 범위 리터럴은 새로운 반복 바인딩을 제공합니다.
C-스타일for (mut int index = 0; index < 10; index++)하나의 제어 바인딩이 반복 간에 업데이트됩니다.
향상된 기능for (char scalar : text)텍스트 트래버설은 텍스트 소유권을 소비하지 않고 Unicode 스칼라를 읽습니다.
Switchswitch (value) { case 1: ... break; }모든 작성된 분기는 명시적으로 break로 끝납니다; 암시적 오류는 없습니다.

표의 줄임표는 Aevix 소스가 아닌 설명 표기법입니다. int는 기본 i32 별칭입니다. float는 기본 f64 별칭입니다. 바인딩은 기본적으로 첫 번째 유형과 불변으로 유지됩니다.

4입니다. 제어 흐름으로 소유권 및 정리 표시 유지

로컬 바인딩은 선언 범위와 중첩 범위에 표시됩니다. 헤더 바인딩에 대한 A는 루프를 탈출하지 않습니다. 눈에 보이는 외부 이름은 중첩된 로컬 선언에 의해 그림자를 드리울 수 없습니다. public 및 private qualified 모듈 또는 형식 선언; 그들은 로컬 바인딩의 범위 또는 수명을 넓힐 수 없습니다.

일반 범위 출구 break, 계속, return 또는 Result 전파 postfix로? 여전히 남아있는 범위에 의해 소유 된 초기화 된 자원을 정리, 역 초기화 순서와 정확히 한 번. 이동된 값은 새로운 소유자를 따른다; 빌린 참조는 단지 참조가 범위를 벗어나기 때문에 파괴되지 않는다.

이러한 구조화된 출구는 강제 안전 정지와는 다릅니다. 각 경우와 기본값은 독립적인 암시적 로컬 범위를 가지고 있습니다. 강제 중지 정리, 다중 레벨 종료에 대한 레이블 및 사용자 정의 반복자 프로토콜은 열려 있습니다. 클린업 명령 지속 정상적인 종료시 성공적인 초기화 완료의 반대입니다. Enum Switch 철저한 분기 검사를 통해 문서 읽기, 수정 및 소비 모드.
