Catalog boundaries

This 69-name inventory covers the established type/API reference catalog, including planned libraries and example-only application errors. Eight entries have implemented 0.2 subsets: BoundsError, CollectionError, ComplexError, FloatError, InputError<T>, IntegerError, RangeError, and TextError. Their subset notes identify supported operations and variants; the other 61 entries remain design/example records. The API tables retain catalog signatures and links, so they do not by themselves establish executable call forms or additional variants. Use the subset notes and linked implementation profiles for current behavior.

The planned error.Error interface and owning error.AnyError carrier and system.IoError console contract belong to the 0.3 roadmap and are not shipped 0.2 declarations or additional implemented entries in this inventory. Error is a behavior interface used through borrowed views; AnyError is the planned sized carrier for Result<T, AnyError>. The selected 0.3 model uses Result rather than Java-style try/catch. Concrete error parameters and explicit mapping retain their normal ownership and exact-type rules.
