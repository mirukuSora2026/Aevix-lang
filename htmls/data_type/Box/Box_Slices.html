1. Own the Payload, Not an Ambiguous Slice

Box<Array<T, N>> owns N initialized inline elements in one fixed extent. It is different from Box<Slice<T>>, which boxes a descriptor that still borrows another owner. The latter does not make the borrowed elements live longer. A dynamic owning sequence remains Vector<T> under the approved collection model; this page does not quietly introduce an unsized BoxedSlice primitive.

2. Direct Fixed-Extent Construction

A large fixed array need not first exist as a large temporary stack value. Builder APIs can reserve the final box and initialize by index. They record exactly how many elements have completed initialization. Failure destroys that prefix once and releases the allocation. Element-producing callbacks and cloning may themselves fail or perform external work; those effects are not rolled back by allocation cleanup.

3. Boxing a Vector Adds a Layer

Box<Vector<T>> owns a vector handle inside a unique heap allocation. The vector still owns its separate contiguous buffer and retains its own capacity, growth, and moved-input rules. This representation can add an allocation rather than saving memory. Moving out the vector transfers its buffer ownership but does not copy the elements. A borrowed nested slice cannot coexist with an operation that reallocates the vector buffer.

4. Views and Element Finalization

Read slices expose initialized elements without allocation; exclusive slices suspend conflicting parent access. A slice cannot grow the fixed extent or the nested vector. Zero-sized elements can have visible constructor, callback, or destructor effects, so zero payload bytes do not eliminate N logical elements. Destruction follows element ownership and the runtime’s normal cleanup policy; external resource release is not guaranteed after forced process termination.

6. Layout, Cost, and Placement

Count products and layouts are checked before allocation. Native alignment and FFI layout are independent of a source type’s name. Fixed-array extraction can move a large inline value; it is not the O(1) handle move of a vector. Borrowing host storage neither uploads it nor grants device access. Asynchronous work needs an explicit resource lease that survives the user-visible completion handle when necessary.
